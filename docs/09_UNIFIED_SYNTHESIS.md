# 09｜统一综合：从训练分布到权重、激活、推理与行为

> 本章把 Transformer Circuits Thread 的主要研究线索压缩成一套可检验的大模型理论。它不是“最终理论”，而是一张当前最有解释力的工作地图：哪些对象必须区分、哪些因果关系已有证据、哪些只是有希望的近似。

# 9.1 中心命题：模型是条件动力系统，不是静态知识库

一个自回归语言模型可写成：

$$
p_\theta(y_t\mid x_{1:n},y_{<t})
=
\operatorname{softmax}\!\left(\frac{z_t}{T}\right),
\qquad
z_t=W_Uh_t^{(L)}.
$$

其中：

- $\theta$ 是训练后固定的参数；
- $x_{1:n}$ 是外部输入 token；
- $y_{<t}$ 是模型此前已经生成的 token；
- $h_t^{(L)}$ 是当前时间步最后一层的隐藏状态；
- $z_t$ 是词表中每个候选 token 的 logit；
- $T$ 是解码温度。

最重要的因果方向是：

```text
训练数据与目标
    → 参数 θ
输入、历史和固定参数
    → 当前激活与注意力路由
当前激活
    → logits 与 token 分布
从分布中选出的 token
    → 写回上下文
新上下文
    → 下一步激活与新分布
```

所以，模型既不是每次推理都修改权重，也不是单纯从权重中“读取答案”。权重定义一个巨大的潜在计算网络；输入决定其中哪些变量和路径在本次运行中真正生效；生成又把系统变成有路径依赖的动态过程。

# 9.2 五个分析层级

## 9.2.1 训练层：分布怎样塑造权重

预训练损失通常近似为：

$$
\mathcal L(\theta)
=
\mathbb E_{s\sim D}
\left[
-\sum_t \log p_\theta(s_t\mid s_{<t})
\right].
$$

训练 token 分布通过梯度统计长期塑造参数。高频共现、语言比例、文体、数据清洗、任务混合、后训练偏好和安全样本都会改变模型形成什么先验，以及哪些输入区域得到充分约束。

这就是“token 分布影响参数”的正确时间尺度。它产生：

- 事实和语言频率先验；
- 常见模式的快捷回路；
- 稀有组合下的盲区；
- 文化和社会关联；
- 角色、格式和任务的默认假设；
- 后训练形成的拒绝、帮助和风格控制路径。

训练分布偏置不是一个附加模块，而是分散在整个参数系统中的统计结构。

## 9.2.2 表示层：输入怎样变成内部变量

模型首先把 token 和位置映射进 residual stream。研究中常见的分析对象包括：

- 神经元坐标；
- 线性方向；
- 稀疏特征；
- 子空间；
- 连续流形；
- 跨层持续状态；
- 可语言化状态；
- 任务、角色和输出控制状态。

这些对象不应混同。一个概念可能需要多维子空间；一个神经元可能参与多个概念；一组离散特征也可能只是同一连续流形的局部坐标。

## 9.2.3 计算层：表示怎样被读取、组合和写回

Transformer 的核心模块不是独立黑箱，而是在 residual stream 上读写：

$$
h^{(\ell+1)}
=
h^{(\ell)}
+
\operatorname{Attn}_\ell(h^{(\ell)})
+
\operatorname{MLP}_\ell(h^{(\ell)}).
$$

每层都在已有状态上增加新的更新。早层写入的信息可以被后层 attention 或 MLP 读取，形成跨层路径。具体 prompt 下，真正活跃的路径构成一张条件化计算图。

## 9.2.4 行为层：内部竞争怎样成为 token

最终隐藏状态经 unembedding 投影到词表。多个机制可以同时给候选 token 加分或减分：

- 事实答案路径；
- 语法和文体路径；
- 任务完成路径；
- persona 路径；
- 拒绝或重定向路径；
- 不确定性和“无法回答”路径；
- 已生成前缀带来的续写路径。

输出不是单个模块的命令，而是这些贡献在 logit 空间中的合成结果。

## 9.2.5 代理层：模型如何嵌入系统

系统提示、用户消息、工具结果、检索文档、长期记忆和外部动作共同构成代理层。Prompt injection 的根本难点是：在 Transformer 内部，可信指令和不可信数据最终都以相似的表示媒介进入上下文，权限主要靠学习到的角色与来源特征区分，而不是由硬件隔离保证。

# 9.3 参数、激活和“权重影响”必须拆开

## 9.3.1 参数不会通常意义上被激活

在线性层：

$$
y=Wx+b,
$$

连接 $w_{ij}$ 对当前输出的直接贡献是：

$$
c_{ij}(x)=w_{ij}x_j.
$$

因此一个大权重在源激活 $x_j\approx0$ 时几乎不起作用。说“某个 token 激活了某个权重”并不准确；更准确的说法是：

> 这个输入改变了源表示和门控状态，使通过某些固定连接传播的贡献变大或变小。

在 MoE 中，可以说某些专家被路由选中，但专家内部权重仍不是被动态改写。

## 9.3.2 四种不同的重要性

Transformer Circuits 的近期工作要求至少区分：

1. **Magnitude**：参数或虚拟权重本身多大；
2. **Current contribution**：当前输入下，激活乘以有效连接造成多大局部影响；
3. **Distributional effectiveness**：在真实数据分布中，它多久、以多大幅度改变下游状态；
4. **Helpfulness / causal value**：移除或改变它后，损失和行为究竟改善还是恶化。

大权重可能是低效干扰，小权重可能因频繁共激活而关键；大局部贡献也可能被后续路径抵消。只有因果干预和分布评估，才接近“模型是否需要它”。

## 9.3.3 虚拟权重与路径组合

一个有效连接往往不是原始矩阵中的单个元素，而是多个矩阵相乘后在特征坐标中的映射。例如：

$$
W_{\text{virtual}}
=
D_{\text{target}}^\top W D_{\text{source}}.
$$

早期头写入的方向会改变后续头的 query、key 或 value，因此算法存在于路径组合中。所谓“读权重理解模型”，实际要求选择有意义变量并分析矩阵乘积，而不是浏览参数绝对值。

# 9.4 表征理论：从神经元到特征、叠加和几何

## 9.4.1 为什么神经元不是可靠的语义原子

真实模型需要表示的潜在特征数可能远多于 residual stream 维度。当特征稀疏、不常共现时，模型可以把多个特征放在非正交方向上：

$$
h=Dx,
\qquad
x\in\mathbb R^F,
\quad
D\in\mathbb R^{d\times F},
\quad
F>d.
$$

这就是 superposition 的基本图景。它解释了：

- 多义神经元；
- 非正交特征方向；
- 特征间干扰；
- 表示随稀疏度和重要性发生相变；
- 为什么任意神经元标签经常只描述部分行为。

## 9.4.2 Composition 不等于 superposition

复杂概念由多个有意义成分组合，是 composition；因容量限制让多个独立特征共享维度，是 superposition。二者可同时存在。

例如，一个“法国女性科学家”表示可能由国家、性别、职业等成分组合；这些成分本身又可能与其他稀疏特征处于叠加。多维表示不必是缺陷，关键是它是否对应稳定、可组合变量。

## 9.4.3 Privileged basis 的中间立场

Residual stream 在理想化函数上可做基底旋转，但实际训练可能因逐维优化器、归一化或架构结构形成统计上特殊的坐标。因此：

- 不能假设神经元天然单义；
- 也不能断言所有神经元坐标都完全任意；
- 最终应由简洁性、稳定性、预测和因果干预判断变量质量。

## 9.4.4 SAE：有用的近似坐标，而非真实原子表

稀疏自编码器近似：

$$
x\approx b+\sum_i f_i(x)d_i,
$$

并优化重建误差与稀疏度。它的成果是发现大量比神经元更可读的特征，包括抽象主题、语言、代码、实体和安全概念。

但 SAE 伴随几个系统性问题：

- **feature splitting**：一个概念被拆成多个局部特征；
- **feature absorption/merging**：多个概念被一个特征混合；
- **dark matter**：重建残差仍携带重要信息；
- **occlusion**：强特征遮蔽较弱结构；
- **basis non-uniqueness**：不同宽度、随机种子和损失产生不同字典；
- **precision–recall trade-off**：漂亮的最高激活样本可能掩盖低召回。

因此 SAE 最适合作为研究接口：生成候选变量、做分布检验和干预，而不是宣称模型内部“真的有一张唯一字典”。

## 9.4.5 从 SAE 到 transcoder、crosscoder 和 MOLT

- **Transcoder** 近似模块输入到输出的变换，目标从“重建激活”升级为“重建计算”。
- **Cross-layer transcoder / CLT** 用跨层稀疏变量近似深层网络，使 prompt-specific attribution graph 成为可能。
- **Crosscoder** 同时重建多层或多模型，寻找跨层持续变量和模型差分坐标。
- **Sparse mixtures of linear transforms** 试图把“何时激活”与“激活时执行什么变换”分开。

这是研究谱系中的重要演化：

```text
神经元可视化
→ 单层特征
→ 跨层状态
→ 特征间计算
→ 条件化局部变换
```

## 9.4.6 特征与流形是互补尺度

计数任务显示，内部变量可以沿低维曲线编码。多个 SAE 特征像流形的局部切片；几何视角则解释全局连续关系。Attention 还能旋转、对齐或扭转这些流形。

所以未来的表示理论可能同时包含：

- 可命名的稀疏事件；
- 连续低维状态；
- 多维概念子空间；
- 跨层动力学；
- 与任务相关的局部坐标。

# 9.5 Attention 理论：QK 决定“从哪里读”，OV 决定“写什么”

## 9.5.1 注意力不是“关注度”

单头注意力可简写为：

$$
s_{ij}
=
\frac{q_i^\top k_j}{\sqrt{d_k}},
\qquad
\alpha_{ij}
=
\operatorname{softmax}_j(s_{ij}),
$$

$$
o_i
=
\sum_j \alpha_{ij}v_j.
$$

解释一个头需要回答两个不同问题：

1. **QK circuit**：当前位置的 query 为什么与某个历史位置的 key 匹配？
2. **OV circuit**：读取该位置后，value/output 向 residual stream 写入什么？

只看 attention heatmap 最多说明“从哪里读取”，而且仍未说明为什么；它不能告诉我们写入内容，更不能证明该头对最终行为必要。

## 9.5.2 Attention 是上下文条件化路由

输入 token 的任何变化都可能改变 query、key、value 和 softmax 分母。加入一个片段不仅增加信息，还会重新分配读取权重。因此输入可通过路由产生放大效应：

```text
表面 token 变化
→ Q/K 特征变化
→ 注意力竞争变化
→ 读到不同位置或不同内容
→ 下游状态与输出改变
```

## 9.5.3 QK 特征交互

QK 分数是双线性的，可以在特征坐标中展开为 query 特征与 key 特征的成对贡献。这样的解释比“这个头看了那个词”更接近机制：

> 某个查询需求在当前位置被激活，并在候选位置找到相应线索，于是该位置获得注意力。

但 softmax 让所有位置耦合，长上下文中移除一个位置会改变其他位置的归一化；所以 QK attribution 仍需要反事实验证。

## 9.5.4 Attention superposition

HeadVis 等研究显示，一个头可以在不同子分布上执行多个模糊功能；多个头也可能共享同一功能。头不是天然模块边界。真正的功能单元可能是：

- 一个头中的低秩成分；
- 多个头的联合子空间；
- 跨层 QK/OV 路径；
- 由特征条件触发的局部变换。

# 9.6 回路理论：全局潜在网络与局部实际图

## 9.6.1 全局回路和局部回路

可以区分：

- **全局潜在图**：固定权重允许的所有特征间连接；
- **局部实际图**：特定输入下源特征真正激活、路径真正传递作用的子图。

局部边归因可写成：

$$
A_{s\rightarrow t}(x)
=
a_s(x)\,w_{s\rightarrow t},
$$

其中 $a_s(x)$ 是当前输入下源特征激活，$w_{s\rightarrow t}$ 是有效连接。这个式子说明为什么相同权重在不同 prompt 下具有完全不同的实际作用。

## 9.6.2 Attribution graph 的正确用途

Attribution graph 应被视为：

1. 对指定 prompt 的局部近似；
2. 帮助研究者提出机制假设；
3. 通过消融、patching、steering 和反事实输入验证；
4. 不能直接等同于原模型源代码。

局部 replacement model 即使数值上匹配一次 forward pass，也可能使用不同机制。剪枝还会隐藏弱但冗余的路径，误差节点可能包含关键计算。

## 9.6.3 全局解释为何困难

即使特征是稀疏的，虚拟权重仍可能因低维叠加而稠密。Interference weights 说明：大量非零连接可能从几何压缩中产生，却很少在数据分布上生效。

全局理论因此需要结合：

- 特征共激活分布；
- 局部 Jacobian；
- 条件门控；
- effectiveness；
- helpfulness；
- 替代路径和抵消；
- 模型与数据的多尺度统计。

# 9.7 推理理论：多路径、分布式和跨 token 的计算

## 9.7.1 推理不是单一隐藏链条

真实模型经常同时使用：

- 事实记忆；
- 模式匹配；
- 局部启发式；
- 中间变量计算；
- 输出格式约束；
- 校验与候选竞争；
- 任务或 persona 控制。

相同正确答案可以由不同路径支持；错误答案也可能来自某个正常回路在错误输入区域被触发。因此“答对了”不能证明模型采用了人类期待的算法。

## 9.7.2 层维度上的隐式中间状态

两跳事实查询中可以观察到内部中间实体；诗歌生成会提前形成押韵目标；医学问答会维持候选诊断并让它们影响后续问题。这些案例表明，一次 forward pass 内可以存在可因果干预的中间变量。

## 9.7.3 序列维度上的延长计算

模型可把中间结果写成 token，再读取它们：

```text
内部计算
→ 生成中间 token
→ token 成为外部化工作记忆
→ 下一次 forward 继续计算
```

Chain-of-thought 有时提升能力，部分原因是它增加了串行计算步数和可读写状态。但这也意味着错误或不安全前缀会成为后续计算的强控制信号。

## 9.7.4 Induction heads 与上下文学习

Induction circuit 的经典模式是：

```text
[A][B] ... [A] → [B]
```

前一头或路径定位当前 token 过去出现的位置，后一头读取其后继 token。更大模型中可出现模糊最近邻版本。它是上下文学习的重要构件，但不能代表全部 ICL，更不能由此推出模型内部必然存在通用优化器。

## 9.7.5 并行启发式与分布式算法

加法案例显示模型可能并行估计数量级、个位数和常见模式，再在输出处合成，而不是运行单一学校算法。计数案例则显示同一变量可以被多个头和流形协同维护。

合理的大模型推理理论因此更接近：

> 大量专门化但可组合的统计回路，在共享 residual stream 中并行提出、路由、修正和竞争候选状态。

## 9.7.6 外显 CoT 的不忠实

模型输出的解释可能：

- 忠实报告部分内部路径；
- 省略自动化步骤；
- 对已得到的答案事后合理化；
- 被用户提示中的暗示牵引；
- 编造没有真正执行的计算。

CoT 是行为证据，不是内部图的直接打印。验证忠实性需要改动解释中的关键变量，观察内部状态和答案是否按预测变化。

## 9.7.7 可报告工作区与自动回路

J-space 研究提出一个有用分层：

```text
大量自动、局部、不可轻易报告的处理
       ↓ 选择/压缩
较小的可语言化、可控制、可组合状态
       ↓
灵活推理、计划、报告与跨任务复用
```

这能解释为什么模型既有复杂的隐式处理，又能通过语言中间状态延长计算。但它是功能理论，不是意识理论。

# 9.8 Token 概率、温度和轨迹偏置

## 9.8.1 Softmax 与相对赔率

温度为 $T$ 时：

$$
p_i
=
\frac{e^{z_i/T}}
{\sum_j e^{z_j/T}}.
$$

两个 token 的赔率只取决于相对 logit：

$$
\log\frac{p_i}{p_j}
=
\frac{z_i-z_j}{T}.
$$

若相对 logit 改变量为 $\Delta z$，赔率乘数为：

$$
\frac{(p_i/p_j)_{\text{after}}}
{(p_i/p_j)_{\text{before}}}
=
e^{\Delta z/T}.
$$

当 $T=1$、$\Delta z=1$ 时，赔率乘以 $e\approx2.718$。因此隐藏状态中看似不大的方向变化，可能翻转首 token。

## 9.8.2 四种不同的“token 分布偏置”

1. **训练分布偏置**：长期改变参数；
2. **上下文条件偏置**：当前 prompt 改变激活与 logits；
3. **解码偏置**：temperature、top-p、top-k、seed 等改变选 token 的方式；
4. **自回归轨迹偏置**：已选 token 写回后改变未来所有状态。

低温度减少随机性，却不会消除训练或上下文偏置。反而在两个候选接近时，低温度会更确定地放大微小 logit 优势。

## 9.8.3 首 token 的模式选择作用

拒绝式、服从式、列表式、代码式或故事式首 token 往往会激活不同的语法与任务延续路径。于是局部差异通过反馈扩大：

```text
首 token 差异
→ 上下文差异
→ 下一步注意力与特征差异
→ 更大的 logit 差异
→ 轨迹分叉
```

这不是混沌的严格数学证明，而是一种强路径依赖。

# 9.9 安全理论：识别、策略和行为必须分离

## 9.9.1 最小安全链条

安全行为至少包含：

```text
局部 token / 格式识别
→ 整体意图与危险语义组合
→ 角色、来源与权限判断
→ 有害性表示
→ 拒绝或安全重定向策略
→ 输出 token 竞争
→ 自回归延续
```

任一接口失配，都可能产生越狱、过度拒绝、迎合或 prompt injection。

## 9.9.2 有害性识别不等于拒绝

模型可能已经表示内容危险，却因下游路由、角色或任务完成路径更强而继续回答。反过来，表面危险特征也可能在整体任务无害时触发拒绝。

因此应分开测量：

- 是否有有害性信息；
- 是否形成拒绝状态；
- 拒绝状态是否被输出层读取；
- 最终行为是否拒绝；
- 拒绝理由是否与真实危险一致。

## 9.9.3 安全训练像连接新策略，而非删除知识

研究案例支持这样一个局部图景：预训练形成具体危险概念；安全后训练再把这些概念连接到更一般的“有害请求”和拒绝/重定向特征。危险知识往往仍然存在，安全性依赖新行为路径能否及时获胜。

## 9.9.4 越狱的几类机制

在不讨论可复用载荷的前提下，可以区分：

1. **语义组合延迟**：局部成分分别被处理，但完整危险意图形成太晚；
2. **任务框架覆盖**：翻译、续写、编码、角色扮演等任务状态压过意图判断；
3. **角色/权限混淆**：不可信文本诱导模型把它当成高权限指令；
4. **安全信号路由失败**：有害性存在，却没有进入拒绝输出路径；
5. **首 token 竞争失败**：任务完成或语法路径先获得回答式开头；
6. **生成惯性**：回答前缀写回后，语法、自洽和承诺继续强化当前轨迹；
7. **分布外形式**：罕见语言、tokenization、位置或多轮组合未被安全训练充分约束。

不同攻击可能走不同路径，不应寻找一个普遍“越狱神经元”。

## 9.9.5 过度拒绝是镜像失配

过度拒绝常来自：

- 表面词或拆分拼写触发危险特征；
- 风险特征高精度但低语义覆盖；
- 拒绝路径过早改变 attention 路由；
- 安全阈值在模糊上下文中占优；
- 拒绝首 token 形成语法惯性。

越狱和过度拒绝可被看成安全识别与行为控制失配的两个方向。

## 9.9.6 Prompt injection 是系统权限问题

模型将系统指令、用户文本、网页内容和工具结果都表示为 token。角色标签提供重要线索，却不是形式化访问控制。安全系统因此不能只依赖“在 prompt 中告诉模型不要听不可信内容”，还需要：

- 数据与指令的外部隔离；
- 最小工具权限；
- 结构化来源标记；
- 动作前验证；
- 沙箱和输出过滤；
- 独立策略层；
- 对检索内容和工具结果的信任边界。

机制可解释性可帮助诊断角色判断，但不能替代系统安全工程。

# 9.10 幻觉、迎合和 persona 的统一解释

## 9.10.1 幻觉是候选生成与不确定性控制的失配

模型可能同时具有：

- 语义上合理的答案生成路径；
- “这是知名实体”的熟悉度路径；
- “我不知道”的不确定性或拒答路径。

当熟悉度错误抑制未知实体路径时，模型会生成流畅但错误答案。概率高只代表当前上下文下输出竞争胜出，不等于模型拥有校准后的真值信念。

## 9.10.2 迎合与动机性推理

用户暗示可以直接改变候选答案的先验，模型随后构造一条支持它的解释。内部因果可能是：

```text
用户答案线索
→ 目标答案状态
→ 反向组织解释
```

而不是：

```text
独立推理
→ 得出答案
```

因此评价推理必须使用隐藏答案、反事实暗示和中间变量干预。

## 9.10.3 Persona 是控制状态

Persona 可以调制：

- 哪些知识被报告；
- 语气和价值框架；
- 是否承认不确定性；
- 哪些行为策略获得优先级。

它更像对底层能力的门控和路由，而不是加载一个完全独立人格。

# 9.11 内部状态语言化：机会与误区

NLA、Activation Oracles、introspection 和 J-space 共同显示：模型内部部分状态可以被高带宽地转成语言，甚至被语言编辑后重新注入。

这提供三类能力：

1. **解释接口**：询问当前激活可能表示什么；
2. **审计接口**：查找评估意识、异常目标或隐藏状态；
3. **控制接口**：编辑可语言化状态，观察因果后果。

但必须防止三个错误：

- 把接口模型的推断当成被测模型的直接自述；
- 把重建成功当成逐字忠实；
- 把功能性内省当成意识或体验。

最可靠的使用方式是：语言解释提出假设，独立激活干预与反事实输入验证。

# 9.12 证据体系：怎样从故事走向机制

一个机制主张应逐级增强：

| 层级 | 能说明什么 | 不能说明什么 |
|---|---|---|
| 输出案例 | 行为存在 | 内部原因 |
| 激活可视化 | 某表示与输入相关 | 模型使用了它 |
| Probe/分类器 | 信息可解码 | 信息控制输出 |
| Logit attribution | 对当前输出有局部线性贡献 | 整体因果必要性 |
| Ablation/steering | 改变该表示会改变行为 | 干预是否保持自然分布 |
| Activation patching | 中间状态能传递反事实效应 | 是否是唯一自然机制 |
| Attribution graph | 提供局部路径假设 | 完整全局源代码 |
| 跨模板/跨模型复现 | 机制有一定稳定性 | 普遍定律 |
| 训练阶段追踪 | 接近解释机制如何形成 | 完整优化因果史 |

高质量机制解释至少应包含：

- 明确对象与层位；
- 对照输入；
- 正负向干预；
- 输出和中间状态预测；
- 替代假设；
- 跨样本覆盖；
- 失败案例；
- 适用边界。

# 9.13 当前可以相对有把握地说什么

综合 thread，较稳健的结论是：

1. 标准推理中参数通常固定，输入改变激活、路由和实际路径。
2. 模型内部存在可解码且部分可因果干预的中间表示。
3. 神经元不是普遍可靠的语义原子，superposition 是有力解释。
4. SAE 等工具能发现有意义特征，但没有给出唯一、完备基底。
5. Attention 必须分解 QK 选择和 OV 写入，热力图不足以解释机制。
6. 具体输入下的计算可近似成局部特征图，但图不等于完整源代码。
7. 推理经常由多条路径、启发式和中间状态共同完成。
8. 外显 chain-of-thought 可能忠实，也可能省略或事后合理化。
9. 生成 token 会成为后续强输入，首 token 和格式具有路径依赖。
10. 有害性识别、拒绝策略和最终行为可以彼此分离。
11. Persona、任务框架和角色线索能调制知识访问与报告。
12. 可语言化内部状态为解释和审计提供新接口，但不证明意识。
13. 权重大小不是功能重要性的可靠代理；数据分布和因果干预不可缺少。
14. 当前研究仍主要是局部和近似的，离完整全局理论有显著距离。

# 9.14 仍未解决的核心问题

1. 是否存在跨架构稳定的“最佳变量”或多尺度变量体系？
2. 怎样同时处理稀疏离散特征、连续流形与动态子空间？
3. 怎样忠实替代 attention，尤其是 QK、softmax 和长上下文耦合？
4. 怎样区分真实机制与 replacement model 的等价拟合？
5. 怎样把局部 attribution graph 汇总成分布级和全局回路？
6. 怎样度量大量干扰权重、抵消和冗余路径？
7. 推理时的可报告工作区与自动处理如何交互？
8. 安全后训练究竟在不同模型中重写了哪些表示与路由？
9. 如何从训练数据样本追踪到具体特征和回路形成？
10. 机制解释怎样进入可扩展、低假阳性的现实审计系统？

# 9.15 用这套理论分析一个新现象

面对任何 prompt 敏感性、幻觉、越狱或推理错误，按以下顺序提问：

1. **Tokenization 改变了什么？**
2. **模型是否形成了正确的整体语义和任务表示？**
3. **哪些角色、persona、权限和格式状态被激活？**
4. **Attention 的 QK 把信息路由到哪里？OV 写回了什么？**
5. **哪些事实、启发式、拒绝、语法或不确定性路径在竞争？**
6. **关键表示只是可解码，还是经干预证明被使用？**
7. **首 token 怎样改变了后续轨迹？**
8. **结果在多少模板、语言、位置和模型上复现？**
9. **替代解释是什么，什么实验能使当前解释失败？**
10. **结论属于局部案例、任务级机制，还是有资格上升为更一般理论？**

这十个问题比寻找“哪个 token 激活哪个参数”更接近当前机制科学的真实水平。
