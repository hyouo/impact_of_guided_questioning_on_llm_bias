# 练习册｜从公式到机制判断

这套练习不是术语背诵。每题都要求你区分对象、写出因果方向、设计对照，或指出一个结论为什么说得过头。

建议先独立作答，再查看[答案与解析](solutions.md)。

## 使用方式

完成一章基础教程后，做对应小节：

```text
第 1 章 → A 组
第 2 章 → B 组
第 3 章 → C 组
第 4 章 → D 组
第 5–6 章 → E 组
第 7 章 → F 组
```

每道机制题至少写出：

```text
对象是什么？
因果方向是什么？
哪些量保持不变？
需要什么正对照和负对照？
最多能得到什么结论？
```

## A 组｜Logits、概率与解码

### A1｜手算赔率

两个 token 的 logits 分别是 $2.4$ 和 $1.7$。

1. 在 $T=1$ 时计算它们的赔率；
2. 在 $T=0.5$ 时重新计算；
3. 解释温度改变了什么，没有改变什么。

### A2｜第三个 token

在 A1 中加入第三个 logit $5.0$：

1. 前两个 token 的赔率是否改变？
2. 前两个 token 各自的绝对概率是否改变？
3. 这说明为什么分析输出竞争时既要看 pairwise logit difference，也要看整个词表？

### A3｜温度为零

解释为什么数学公式要求 $T>0$，而很多 API 又允许 `temperature=0`。这两个“0”是否是同一含义？

### A4｜首 token 不是全部

构造一个反例：token A 在第一步概率略高于 token B，但由于解码约束或第三个候选存在，A 并不一定被选中。

## B 组｜权重、激活与 input

### B1｜最大权重反例

给定：

$$
W=[100,\ 3,\ 0.5],
\qquad
x=[0,\ 2,\ 20]
$$

计算每条连接的直接贡献，并按：

1. 权重绝对值；
2. 当前贡献绝对值；

分别排序。为什么两个排序不同？

### B2｜三个时间尺度

把下面五个事件放到正确时间尺度：训练、单次 forward、自回归生成。

- 梯度更新参数；
- prompt 改变 query；
- 选出的 token 写回上下文；
- 数据频率形成长期先验；
- 下一步隐藏状态改变。

### B3｜格式干预

用户只在 prompt 末尾增加一个换行。至少列出四种可能同时发生的变化，并说明为什么不能把输出差异直接归因于“语义改变”。

### B4｜条件计算实验

设计一个最小固定权重 ReLU 网络，使两个输入分别激活两个不同输出。写出：

- 权重；
- bias；
- 两个输入；
- 激活；
- 输出。

## C 组｜Attention 与回路

### C1｜QK 与 OV

对于以下观察分别判断主要涉及 QK、OV，还是两者都不能单独解释：

1. 某个位置的 attention weight 从 0.1 变为 0.8；
2. attention pattern 完全相同，但输出向量改变；
3. 移除一个头后目标 token logit 降低；
4. 一个头总是关注句首。

### C2｜相同 key，不同 value

构造两个历史位置，使它们对 query 的 score 完全相同，但 value 不同。最终输出会怎样？这为什么说明 attention heatmap 不包含全部内容？

### C3｜Softmax 竞争

在三个位置的 attention scores 中，只提高一个位置的 score。解释为什么其他两个位置的权重会下降，即使它们自己的 score 没有改变。

### C4｜Induction 回路

用自己的话解释 `[A][B] ... [A] → [B]` 回路。至少指出：

- 哪个信息需要先被写入；
- 后一个头的 query/key 要匹配什么；
- OV 要复制什么；
- 哪种消融是合理负对照。

## D 组｜特征、叠加与可解码性

### D1｜神经元与特征

给出两个不同例子说明：

1. 一个神经元可以参与多个特征；
2. 一个特征可以分布在多个神经元上。

### D2｜Superposition 何时划算

为什么特征稀疏时，非正交共享维度的干扰成本可能较低？如果两个特征经常共同激活，会发生什么？

### D3｜SAE 解释边界

一个 SAE feature 在 20 个最高激活样本中都与“法律文本”有关。列出至少四个尚未被证明的命题。

### D4｜Probe 反例

构造二维隐藏状态 $h=[c,d]$，让：

- 外部 probe 从 $d$ 精确读出标签；
- 原模型输出只依赖 $c$。

分别预测消融 $c$ 和消融 $d$ 的结果。

## E 组｜推理、生成与安全路由

### E1｜正确答案不证明正确算法

列出一个任务中至少三条可能同时得到正确答案的路径：记忆、启发式、组合推理。设计一个反事实输入来区分它们。

### E2｜CoT 忠实性

模型先得到答案，再写出一段合理解释。仅看文字，你能证明解释忠实吗？至少提出三种内部或反事实测试。

### E3｜生成惯性

解释为什么模型写出列表第一项后，更容易继续列表。把解释写成：

```text
已生成 token
→ 新上下文状态
→ 哪些特征或约束增强
→ 哪类后续 token 概率提高
```

### E4｜安全链条

把一次安全行为拆成：识别、权限绑定、策略形成、输出竞争、自回归延续。对每个环节写出一种可能失败方式。

### E5｜Prompt injection 的系统边界

为什么“在系统提示中写不要听文档指令”不是强访问控制？给出三项模型外防御措施，并说明它们控制的是哪一层风险。

## F 组｜因果证据与实验设计

### F1｜证据等级

把下面结果放入最合适的证据等级：

- softmax 恒等式数值验证；
- 单个 prompt 的 attention heatmap；
- 一个开放模型上的 residual patch 恢复；
- 五个模型、多个模板上的同一回路预测被独立复现；
- 透明 toy 中构造的 probe 反例。

### F2｜Patching 恢复率

已知：

```text
clean margin = 4
corrupt margin = -2
patched margin = 1
```

计算恢复率：

$$
R=\frac{m_{patched}-m_{corrupt}}{m_{clean}-m_{corrupt}}
$$

它支持什么？不能证明什么？

### F3｜Steering 对照

某方向 steering 后目标行为增加。设计至少四个对照，用来区分“目标机制方向”与“任意大扰动”。

### F4｜机制实验卡

为以下命题写一张完整实验卡：

> 某个中层状态承载了任务所需的中间实体。

必须包含：模型与数据、位置、指标、干预、保持量、正对照、负对照、反证条件和结论边界。

### F5｜审稿练习

评审下面的结论：

> “我们训练了一个准确率 99% 的安全 probe，因此模型已经可靠理解危险性，而且部署时一定会拒绝危险请求。”

逐句指出哪些推断没有被证据支持，并提出最低限度的补充实验。

## 综合项目

选择一条核心 claim，完成一份两页研究说明：

1. 用公式或计算图精确定义；
2. 给出一个透明 toy；
3. 给出一个可能反例；
4. 设计开放模型观察；
5. 设计内部因果干预；
6. 说明跨模板和跨模型复现要求；
7. 明确不能从结果推出什么。

推荐从 C05“可解码不等于因果使用”或 C06“自回归反馈产生路径依赖”开始。
