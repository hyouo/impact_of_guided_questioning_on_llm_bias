# 练习册｜把“看懂”变成“会分析”

这份练习册不是术语测验。它检查的是你能否：

```text
分清对象
→ 写对因果方向
→ 做出数值预测
→ 选择合适干预
→ 限制结论范围
```

建议先独立作答，再查看[答案与解析](solutions.md)。每一道题都应写出理由；只有结论没有推导，不算完成。

## 使用方法

- 完成一章课程后，做对应题组；
- 数值题尽量先手算，再运行实验核对；
- 机制题至少写一个替代解释；
- 实验题必须写正对照、负对照和反证条件；
- 安全题只讨论抽象机制或无害代理，不构造可复用攻击载荷。

难度标记：`基础` 检查概念，`推导` 需要计算，`研究` 需要设计实验或限制结论。

# A｜模型作为条件系统

对应课程：[第 1 章](../course/01-model-as-conditional-system.md)；对应实验：C03。

### A1｜三个时间尺度（基础）

把下列变化分别归入“训练”“单次前向传播”“自回归生成”中的一个或多个层次，并解释原因：

1. 某种语言在语料中占比提高；
2. 用户在 prompt 末尾增加一个换行；
3. 第一个输出 token 从“是”变成“否”；
4. 对模型进行一次 LoRA 微调；
5. 把 temperature 从 1 改成 0.5。

### A2｜纠正一句话（基础）

改写下面这句话，使其在标准 Transformer 推理语境下更准确：

> 这个 token 激活了安全参数，所以模型拒绝了。

### A3｜因果链补全（研究）

用户把一句普通问题改写成角色扮演格式，模型输出发生变化。至少写出四个可能中介，并说明只看最终文本为什么无法区分它们。

### A4｜固定权重下的输入条件计算（实验）

先运行：

```bash
llm-theory-lab explain C03
llm-theory-lab run-toy --ids C03 --output-dir reports/workbook-a
```

然后完成四步：

1. 在看指标前，预测三种输入状态分别会激活哪些特征；
2. 记录本实验中保持不变的权重和被改变的输入；
3. 说明输出翻转为什么不意味着参数被 prompt 改写；
4. 写出一个能让 C03 的当前实现失败、但不反驳一般命题 $h=f_\theta(x)$ 的代码改动。

# B｜权重、激活、logits 与温度

对应课程：[第 2 章](../course/02-weights-activations-and-logits.md)；对应实验：C01、C02。

### B1｜当前贡献（推导）

某线性层的一行权重为：

$$
W=[8,\;-2,\;0.5]
$$

三个源激活分别为：

$$
a=[0,\;3,\;10].
$$

计算每条连接的直接贡献，以及该行在不考虑偏置时的总输出。哪条绝对权重最大？哪条当前贡献绝对值最大？

### B2｜分布有效性（推导）

连接 A 的权重为 10，只在 1% 样本上以激活 0.05 出现；连接 B 的权重为 1，在所有样本上以激活 1 出现。用

$$
E[(wa)^2]
$$

作为玩具 effectiveness 指标，比较两者。这个指标仍遗漏了真实网络中的哪些因素？

### B3｜赔率（推导）

两个 token 的 logit 差为 $1.2$。分别计算 $T=0.5$、$T=1$、$T=2$ 时的赔率 $p_i/p_j$。

### B4｜首 token 翻转（研究）

隐藏状态变化 $\Delta h$ 的范数很小。为什么仍可能翻转两个候选 token 的顺序？请使用

$$
\Delta(z_i-z_j)=(u_i-u_j)^\top\Delta h
$$

解释。还需要知道哪些量，才能判断是否真的翻转？

### B5｜运行并修改（实验）

运行：

```bash
llm-theory-lab explain C01
llm-theory-lab run-toy --ids C01 C02 --output-dir reports/workbook-b
```

然后打开 `src/llm_theory_lab/experiments/weights.py`，只修改稀有特征的激活概率。先预测 effectiveness 比值怎样变化，再运行核对。不要为了得到 `pass` 调参数；记录预测错误。

# C｜Attention 与 circuits

对应课程：[第 3 章](../course/03-attention-and-circuits.md)；对应实验：C04。

### C1｜QK 与 OV（基础）

对下面两种变化分别判断主要影响 QK、OV，还是两者都可能影响：

1. 改变当前位置的 query 方向；
2. 保持 attention 权重不变，替换被读取位置的 value；
3. 改变历史 token 的表示；
4. 改变输出矩阵 $W_O$。

### C2｜Softmax 耦合（推导）

某个 query 对三个位置的 attention scores 为 $[0,0,0]$。把第一个位置的 score 改成 2 后，计算前后 attention 分布。为什么不能说“只改变了第一个位置的权重”？

### C3｜热图不是机制（研究）

你发现一个头在正确答案 token 上有很高 attention。写出至少四个仍未解决的问题，并为其中两个设计干预。

### C4｜路径组合（研究）

一个早层头把“前一个 token”信息写入 residual stream，后层头使用它定位匹配位置。为什么单独查看任何一个头都可能低估机制？请用“写入—读取—组合”描述回路。

### C5｜运行并解释（实验）

运行：

```bash
python examples/03_attention_routing.py
llm-theory-lab explain C04
llm-theory-lab run-toy --ids C04 --output-dir reports/workbook-c
```

不要只报告最高 attention 位置。至少同时报告：score、归一化权重、聚合 value、输出变化，以及这个玩具实验不能说明什么。

# D｜特征、superposition 与基底

对应课程：[第 4 章](../course/04-features-and-superposition.md)；对应实验：C06。

### D1｜Composition 与 superposition（基础）

分别给出一个 composition 和一个 superposition 的例子。解释为什么“表示是多维的”并不能自动证明存在 superposition。

### D2｜过完备表示（推导）

五个单位特征方向被放入二维平面。为什么它们不可能两两正交？当特征很稀疏时，这仍可能有用的原因是什么？

### D3｜基底不唯一（研究）

设表示变换为 $h'=Rh$，其中 $R$ 可逆。写出怎样同步修改上游或下游线性权重，使模型函数保持不变。这个事实对“某个神经元就是某个概念”的说法有什么影响？

### D4｜评价一个 SAE 特征（研究）

某 SAE 特征的最高激活样本都与“法律文本”有关。设计一份最小评价方案，至少包含：正样本、困难负样本、召回、特异性、重建残差和因果干预。

# E｜推理与自回归反馈

对应课程：[第 5 章](../course/05-reasoning-and-feedback.md)；对应实验：C05。

### E1｜层维度与序列维度（基础）

分别解释：

- 一次 forward pass 内的隐式中间状态；
- 把中间结果写成 token 后继续计算。

为什么“模型没有写出思维链”不等于“模型内部没有中间计算”？

### E2｜相同答案，不同机制（研究）

设计两个系统，它们在训练集上都能正确回答同一类问题，但一个使用规则，另一个使用记忆。给出能区分两者的反事实测试。

### E3｜反馈分叉（推导）

一个简化系统的状态更新为：

$$
h_{t+1}=h_t+f(y_t).
$$

若 token A 的反馈为 $[0.5,-0.1]$，token B 的反馈为 $[-0.1,0.5]$，初态为 $[0,0]$，分别强制 A/B 作为首 token。计算一步后的状态，并说明为什么后续 logits 可能逐渐分叉。

### E4｜CoT 忠实性（研究）

模型给出正确答案和一段合理解释。列出三种内部机制，其中只有一种使这段解释忠实。设计一个能检验解释是否依赖关键中间变量的实验。

# F｜从相关到因果

对应课程：[第 6 章](../course/06-causal-interpretability.md)；对应实验：C07、C08。

### F1｜证据等级（基础）

对下列证据从弱到强排序，并说明你的排序依赖哪些条件：

- 高激活样本可视化；
- 线性 probe 准确率；
- 等范数随机方向对照下的 steering；
- clean/corrupted activation patching；
- 跨模板、跨模型复现的反事实预测。

### F2｜可解码但未使用（研究）

构造一个二维隐藏状态，其中第二维完美编码标签，但输出头只读取第一维。说明 probe、消融和输出变化分别会得到什么结果。

### F3｜必要与充分（基础）

解释以下四句话的区别：

1. 变量与行为相关；
2. 变量可被解码；
3. 移除变量会破坏行为；
4. 注入变量会恢复行为。

哪一项分别更接近必要性和充分性？为什么仍不能自动证明机制唯一？

### F4｜Patching 对照（研究）

一个 layer-position patching 热图在第 8 层最后位置出现高峰。至少设计四个负对照，并说明每个对照排除什么替代解释。

### F5｜替代模型忠实性（研究）

一个 transcoder 能很好重建原模型输出，并给出非常稀疏的归因图。为什么仍可能 mechanistically unfaithful？你会怎样测试？

# G｜安全与权限路由

对应课程：[第 7 章](../course/07-safety-routing.md)；对应实验：C09。

### G1｜分层状态（基础）

把安全行为拆成至少四个内部或系统层次。为什么“检测到风险”不蕴含“最终拒绝”？

### G2｜越狱的机制类别（研究）

不用任何真实攻击字符串，列出五类可能导致安全行为失配的机制位置，例如语义组合、角色判断、注意力读取、策略竞争和生成反馈。对每一类写一个防御性测量方法。

### G3｜Prompt injection 与内容安全（基础）

解释 prompt injection 为什么首先是“指令—数据—权限”问题，而不只是“内容是否有害”的分类问题。

### G4｜无害代理设计（研究）

使用“公开文件/受限文件”“普通用户/管理员”“继续/拒绝/澄清”等标签，设计一个无害代理实验，分别测量：内容识别、权限识别、策略状态和最终动作。写出至少一个识别正确但动作错误的测试条件。

# 完成标准

你不需要把所有公式背下来。完成课程后，至少应能在没有提示的情况下做到：

- 画出训练、前向传播和生成反馈的因果链；
- 区分参数、激活、特征、回路、logit、概率和行为；
- 手算简单 softmax 赔率与连接贡献；
- 对 attention、probe、steering 和 patching 各写出一个不能推出的结论；
- 为机制主张设计正负对照和反证条件；
- 对安全问题使用“识别—权限—策略—输出—反馈”的分层框架。
