# 练习册答案与解析

先独立完成[练习册](index.md)，再看这里。很多题没有唯一措辞，但答案必须满足两个标准：

1. 因果方向正确；
2. 结论不超过证据。

---

# A｜模型作为条件系统

## A1｜三个时间尺度

1. **某种语言在语料中占比提高：训练层。** 它改变梯度统计，长期塑造参数和先验。
2. **prompt 末尾增加换行：单次前向传播层。** 它可能改变 tokenization、位置、激活、attention 和 logits；若随后生成，也会继续影响自回归轨迹。
3. **首 token 从“是”变成“否”：自回归生成层。** 该 token 被写回上下文，改变后续计算。若差异源于输入或采样，它也有前向传播或解码层的上游原因。
4. **LoRA 微调：训练层。** 它改变可学习参数或低秩增量，不是普通推理时的上下文效应。
5. **temperature 从 1 改成 0.5：解码层。** 给定同一 logits，隐藏状态不因温度本身改变；但选出的 token 可能改变，继而影响下一步状态。

关键是不要把“同一次请求中先后发生的环节”混成一种时间尺度。

## A2｜纠正一句话

一种更准确的写法：

> 这个输入改变了当前表示，使风险、角色或策略相关特征获得不同激活；固定权重将这些激活路由到拒绝相关输出路径，最终使拒绝式 token 在 logit 竞争中占优。

仍需保留不确定性：除非做了干预，不能只凭输出断言具体安全特征或路径确实承担因果作用。

## A3｜可能中介

至少包括：

- tokenizer 和序列长度变化；
- 角色/persona 表征变化；
- 任务类型从问答变成故事续写；
- 指令优先级或来源判断变化；
- attention 读取位置变化；
- 安全策略状态变化；
- 首 token 与格式前缀变化。

最终文本只显示合成后的行为。不同内部路径可能产生相同文本，同一路径也可能因采样产生不同文本，因此需要隐藏状态测量、成对对照和因果干预。

## A4｜固定权重下的输入条件计算

C03 的关键不是“模型在不同输入下输出不同”这一显然行为，而是保持同一组 feature map、bias 和 output map 不变，只替换输入状态，并直接观察中间特征与 logits 怎样变化。

合格回答应包含：

1. **预测。** 任务证据、策略证据和不确定性输入应分别提高不同潜在特征；具体以实验中的矩阵定义为准，不应在看结果后倒写预测。
2. **不变量。** 权重矩阵、偏置、输出映射和选择规则保持不变；改变的是输入向量。
3. **解释。** 输出翻转来自 $f_\theta(x)$ 对不同 $x$ 的条件响应，不需要、也不意味着 $\theta$ 被 prompt 临时改写。
4. **局部失败不等于一般反证。** 例如把三个测试输入改成完全相同，或把输出映射改成所有列相同，会让当前实验不再显示输出差异，但只破坏了操作化或构造；它没有反驳“固定参数函数可以对不同输入产生不同状态”这一一般命题。

真正能削弱一般命题的结果必须表明：对所讨论的确定性函数，输入变化在原则上无法引起内部状态或输出变化；这与函数定义本身矛盾。因此 C03 主要是教学演示和概念纠错，不是需要经验发现的普遍定律。

# B｜权重、激活、logits 与温度

## B1｜当前贡献

逐连接贡献为：

$$
[8\times0,\;-2\times3,\;0.5\times10]
=
[0,\;-6,\;5].
$$

总输出为：

$$
0-6+5=-1.
$$

绝对权重最大的是第一条连接 $|8|$；当前贡献绝对值最大的是第二条连接 $|-6|$。这正说明 magnitude 与 contribution 不同。

## B2｜分布有效性

连接 A：

$$
E[(wa)^2]
=
0.01\times(10\times0.05)^2
=
0.0025.
$$

连接 B：

$$
E[(wa)^2]
=
(1\times1)^2
=
1.
$$

尽管 A 的权重大十倍，这个玩具分布上 B 的 effectiveness 高得多。

遗漏因素包括：激活幅度的完整分布、目标门控、LayerNorm、attention、其他路径抵消、冗余、输出方向、损失曲率，以及该连接的改变究竟有益还是有害。

## B3｜赔率

赔率为：

$$
\frac{p_i}{p_j}=e^{1.2/T}.
$$

因此：

- $T=0.5$：$e^{2.4}\approx11.02$；
- $T=1$：$e^{1.2}\approx3.32$；
- $T=2$：$e^{0.6}\approx1.82$。

低温放大已有 logit 差，但不改变产生 logits 的隐藏计算。

## B4｜首 token 翻转

真正影响两个 token 排序的是：

$$
(z_i-z_j)_{\text{new}}
=
(z_i-z_j)_{\text{old}}
+
(u_i-u_j)^\top\Delta h.
$$

即使 $\lVert\Delta h\rVert$ 很小，只要它与差分方向 $u_i-u_j$ 高度对齐，并且原始 margin 很小，就可能翻转顺序。

需要知道：原始 logit margin、差分方向、内积大小、其他 token 的 logits，以及解码规则。翻转 $i/j$ 顺序也不一定使其中一个成为全词表 top-1。

## B5｜运行并修改

稀有特征激活概率提高时，在激活幅度分布不变的条件下，$E[(wa)^2]$ 近似按激活概率线性提高。正确报告应同时说明随机采样误差，并保留预测与实际不一致的情况。

# C｜Attention 与 circuits

## C1｜QK 与 OV

1. 改变 query：主要直接影响 **QK**，但新的读取分布会间接改变输出聚合。
2. 保持 attention 权重不变、替换 value：直接影响 **OV/写回内容**。
3. 改变历史 token 表示：通常 **两者都可能**，因为同一表示可进入 key 和 value 投影。
4. 改变 $W_O$：影响 **写回内容**，不直接改变 softmax attention 权重。

## C2｜Softmax 耦合

初始 scores 为 $[0,0,0]$：

$$
\alpha=[1/3,1/3,1/3].
$$

修改为 $[2,0,0]$：

$$
\alpha
=
\frac{[e^2,1,1]}{e^2+2}
\approx[0.787,0.107,0.107].
$$

第一个位置上升的同时，其他两个位置下降。softmax 是归一化竞争，不能把某个位置的 attention weight 当作独立旋钮。

## C3｜热图不是机制

仍需回答：

- 为什么 QK 给该位置高分？
- 被读出的 value 是什么？
- 写回方向是否提高目标 logit？
- 该头是否必要，还是存在冗余头？
- 效应是否跨样本稳定？
- 高 attention 是否只是无害的复制或分隔符行为？

干预示例：冻结 attention pattern 后替换 value；或保持 value 不变，patch query/key 相关状态；也可消融该头并与随机头、错误层和等范数干预比较。

## C4｜路径组合

早层头写入“前一 token”信息，本身可能不直接提高最终答案 logit。后层头的 query/key 读取该信息后，才形成“找到先前匹配 token 并复制其后继”的算法。完整机制位于矩阵和模块的组合：

```text
早层写入前 token 特征
→ residual stream 保存
→ 后层 QK 读取该特征并定位
→ 后层 OV 复制目标内容
→ unembedding 提高目标 token
```

只看单头会漏掉跨层组合。

## C5｜运行并解释

合格报告至少区分：未归一化 score、softmax 权重、value 聚合、输出向量变化和最终行为。玩具结果只说明固定矩阵下输入可以改变路由和写回，不证明真实模型某个头具有单一语义。

# D｜特征、superposition 与基底

## D1｜Composition 与 superposition

Composition 示例：国家、职业和时间等成分组合成“20 世纪法国数学家”的表示。Superposition 示例：多个很少共现的独立特征共享同一低维空间中的非正交方向。

多维表示只说明信息分布在多个坐标上；它可能是有意义组合、冗余编码、连续流形或子空间，不必是容量压缩造成的 superposition。

## D2｜过完备表示

二维空间最多容纳两个两两正交的非零方向，因此五个方向必有非零内积。若特征稀疏、很少共激活，非正交干扰只在少数输入出现；容量收益可能大于干扰代价。

## D3｜基底不唯一

若 $h'=Rh$，下游映射 $y=Wh$ 可改写为：

$$
y=WR^{-1}h'.
$$

因此新下游权重为 $W'=WR^{-1}$。上游若原本产生 $h=Ux$，则可以令 $U'=RU$。

整体函数不变，但单个坐标改变。这说明神经元语义需要额外证据，不能仅凭某个坐标的高激活样本认定它是唯一基本概念。

## D4｜评价 SAE 特征

最小方案包括：

- 来自不同来源的法律文本正样本；
- 含相似格式但非法律语义的困难负样本；
- 包含法律语义但词汇不同的召回测试；
- precision、recall、激活分布和稳定性；
- 不同字典宽度、seed、层上的匹配；
- 重建残差是否仍携带同类信息；
- feature ablation、pinning 或 patching；
- 等范数随机方向、相关特征和错误位置对照。

最高激活样本漂亮，只说明局部 precision 可能较高，不保证完整语义或高 recall。

# E｜推理与自回归反馈

## E1｜层维度与序列维度

层维度计算是在一次 forward pass 中，前层写入中间状态，后层继续读取和组合；它可以完全不出现在文本中。序列维度计算则把中间结果显式或隐式地编码为已生成 token，后续 forward pass 再读取。

因此没有外显 CoT 只说明没有输出某种文字，不说明网络内部没有中间变量。

## E2｜相同答案，不同机制

规则系统根据组合规律计算；记忆系统查找训练集中相同或相近条目。区分测试可以使用：

- 未见过的组合；
- 保持规则但替换实体名称；
- 反事实映射；
- 极端长度或结构外推；
- 干预候选中间状态。

若只测试训练分布附近，两种机制可能行为等价。

## E3｜反馈分叉

强制 A 后：

$$
h_1=[0.5,-0.1].
$$

强制 B 后：

$$
h_1=[-0.1,0.5].
$$

若输出映射分别偏好与两个坐标对齐的 token，A 状态会提高未来 A，B 状态会提高未来 B；重复写回后差异可以累积。真实模型不一定总是正反馈，还可能出现校正、终止或竞争路径。

## E4｜CoT 忠实性

可能机制：

1. 模型先计算关键中间变量，CoT 报告该变量并据此得到答案；
2. 模型通过记忆得到答案，再生成合理解释；
3. 用户暗示答案，模型围绕暗示构造解释。

可以构造中间变量反事实：patch 或修改关键状态，检查答案和解释是否按机制预测共同变化；同时加入相同答案但不同推导路径、错误中间步骤和隐藏暗示对照。

# F｜从相关到因果

## F1｜证据等级

一般从弱到强可写为：

```text
激活可视化
→ probe
→ 带随机对照的 steering
→ clean/corrupted patching
→ 跨分布反事实预测与复现
```

但排序依赖实现质量。一次不自然的整向量 patch 可能比精心设计的干预更难解释；一个高容量 probe 可能自己计算标签。证据强度由对照、自然性、特异性、复现和预测能力共同决定，而不是工具名称自动决定。

## F2｜可解码但未使用

设：

$$
h=[c,n],
\qquad
z=[2c,-2c].
$$

$n$ 完美编码某标签，但输出只依赖 $c$。probe 可以从 $n$ 达到 100% 准确率；消融 $n$ 不改变 logits；消融 $c$ 会改变输出。这构成“可解码不蕴含被使用”的反例。

## F3｜必要与充分

- 相关：共同变化；
- 可解码：外部读出器能恢复信息；
- 移除后破坏：更接近必要性；
- 注入后恢复：更接近充分性。

必要和充分都依赖干预方式与范围。冗余路径会使真实变量不显得必要；强人工注入可能让一个非自然变量显得充分；即使某状态既必要又充分，也可能仍有多个等价表征或更细中介。

## F4｜Patching 对照

至少包括：

- 错误层：排除任意层整向量替换都有效；
- 错误位置：排除全局状态污染；
- 随机向量或置换样本：排除范数/分布效应；
- clean/corrupted 反向 patch：检查方向性；
- 相同 token 长度但无关语义对照：排除位置形状；
- component-level patch：区分 attention、MLP 或 residual；
- 多模板重复：排除单 prompt 故事。

## F5｜替代模型忠实性

替代模型可能重建相同输出，却使用不同内部路径；它还可能把原模型的稠密或并行计算压缩成一条看似稀疏的故事。测试方式包括：

- 比较原模型和替代模型的干预响应；
- 对归因图预测的新反事实做原模型实验；
- 检查误差节点和重建残差；
- 比较不同替代模型是否给出相同机制；
- 测试路径消融是否在原模型中产生预测效应。

# G｜安全与权限路由

## G1｜分层状态

可拆为：

```text
内容语义识别
→ 风险属性表征
→ 来源/角色/权限判断
→ 策略状态（回答、拒绝、澄清、重定向）
→ 输出 token 竞争
→ 自回归反馈
```

风险检测只是其中一个输入。策略可能未形成、未被下游读取，或在 logit 竞争中被任务完成、格式和角色路径压过。

## G2｜机制类别与防御性测量

示例：

- 语义组合延迟：测量整体风险表示随层/位置何时出现；
- 角色/权限错误：使用内容相同、来源标签不同的成对输入；
- attention 未读取安全证据：做 QK/OV 分析和 patching；
- 策略竞争失败：测量拒绝/回答相关 logit difference；
- 首 token 反馈：比较替代安全前缀后的后续分布。

这些是防御性测量类别，不应转化成自动搜索绕过字符串。

## G3｜Prompt injection 与内容安全

内容安全问“这段内容是否危险”；prompt injection 还问“这段文本是否有权控制系统”。无害文档也可能包含伪指令，危险内容也可能只是被引用分析。模型需要区分数据、指令、来源和权限，而这些往往共享同一 token 表示媒介。

## G4｜无害代理设计

输入变量可以包括：

- 文件类别：公开/受限；
- 用户角色：普通/管理员；
- 文本来源：系统/用户/检索文档；
- 目标动作：继续/拒绝/澄清。

分别训练或测量内容分类器、权限分类器、策略隐藏状态和动作 logits。一个识别正确但动作错误条件是：受限文件被正确识别，普通用户也被正确识别，但任务完成特征压过拒绝策略，最终选择继续。随后可 patch 策略状态，检查动作是否恢复。

# H｜综合研究设计

## H1｜三条强度不同的假设

示例：

**H1，观察性。** 对固定模型，增加换行会改变 token IDs、序列长度或最终位置隐藏状态。指标是 token 差异和层间 cosine distance。若所有成对输入完全相同，则该具体操作化失败。

**H2，局部因果。** 某层最终位置状态传递格式变化对指定 logit difference 的部分效应。指标是 patching recovery。若候选层不优于随机层/位置，则命题被削弱。

**H3，跨分布机制。** 同一中介在多个模板、语言和模型上稳定预测格式效应。指标是预注册跨样本效应与复制率。若效应只在单一模板出现，则不能支持稳定机制。

三条假设强度依次提高，所需证据也提高。

## H2｜完整实验卡

没有唯一答案。合格答案必须确保：

- claim 指向明确对象；
- baseline 与 intervention 只改变目标因素；
- invariants 可核查；
- 正负对照具有具体排除作用；
- 指标在看结果前定义；
- falsifier 不是“代码报错”；
- 允许结论与证据等级匹配；
- 安全主题不包含操作性绕过内容。

## H3｜审稿人模式

高质量回答不只是挑毛病，而是识别“哪一个追加实验最能区分主要机制与替代解释”。重写结论时，优先使用：

> 在模型 M、数据 D、干预 I 和指标 Y 下，我们观察到……；结果支持……作为候选机制，但不能排除……，也不能外推到……。

# 自我评分量表

每项按 0–2 分：

| 能力 | 0 | 1 | 2 |
|---|---|---|---|
| 对象区分 | 混淆参数、激活、特征和行为 | 能定义，但分析时仍混用 | 能稳定按层次表述 |
| 数学推导 | 只记结论 | 能跟随推导 | 能独立计算并解释边界 |
| 因果方向 | 从输出直接猜内部机制 | 能提出中介 | 能设计干预区分中介 |
| 对照设计 | 无对照 | 有一个一般对照 | 正、负、随机、错误层/位置对照明确 |
| 证据边界 | 一次结果外推全部模型 | 会写 caveat | 结论精确绑定模型、数据和干预 |
| 反证能力 | 只寻找支持 | 能接受失败 | 预先写 falsifier 并保留不确定结果 |

总分不重要；薄弱项决定下一步学习。低于 8 分时，回到对应课程和实验，而不是继续堆更多论文。
