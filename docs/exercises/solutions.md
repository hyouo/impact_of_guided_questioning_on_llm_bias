# 练习答案与解析

答案不是唯一措辞。重点是因果方向、适用范围和证据边界是否正确。

---

## A 组

### A1

Logit 差：

$$
\Delta z=2.4-1.7=0.7
$$

当 $T=1$：

$$
\frac{p_1}{p_2}=e^{0.7}\approx2.014
$$

当 $T=0.5$：

$$
\frac{p_1}{p_2}=e^{1.4}\approx4.055
$$

温度改变相对 logit 的缩放和概率分布尖锐度，不改变原始 logits，也不改变两个 token 在原始 logit 中谁更高。

### A2

前两个 token 的赔率不变，因为：

$$
\frac{p_1}{p_2}=e^{(z_1-z_2)/T}
$$

分母会约掉。但第三个高 logit 增加 softmax 总分母，使前两个 token 的绝对概率都下降。这说明 pairwise odds 适合分析两个候选的相对竞争，绝对采样概率还依赖整个词表。

### A3

数学温度必须满足 $T>0$。当 $T\to0^+$ 时，分布趋向把质量集中到最大 logit，但直接代入零会除零。API 的 `temperature=0` 通常是实现层面的 greedy/argmax 开关，不是数学 softmax 的零温度值。

### A4

例如 top-$k=1$ 会确定性选择全词表最高 token；若 A 只比 B 高，但第三个 C 更高，A 不会被选。又如受语法约束的解码器可以屏蔽 A，即使它未经约束时赔率更高。

## B 组

### B1

逐连接贡献：

$$
W\odot x=[0,6,10]
$$

按权重绝对值排序：第一、第二、第三连接。按当前贡献绝对值排序：第三、第二、第一连接。差异来自输入激活：连接作用不是只由 $w$ 决定，而是由 $wx$ 决定。

### B2

- 梯度更新参数：训练；
- prompt 改变 query：单次 forward；
- 选出的 token 写回上下文：自回归生成；
- 数据频率形成长期先验：训练；
- 下一步隐藏状态改变：自回归生成中的下一次 forward。

### B3

换行可能同时改变：tokenization、序列长度、最后位置、位置编码、attention 可读取位置、格式/段落特征和任务边界判断。输出变化不能自动归因于语义，因为表面形式与位置结构也变了。

### B4

一种最小构造：

$$
W=I_2,\quad b=0,
\quad x_A=[1,0],\quad x_B=[0,1]
$$

ReLU 后分别为 $[1,0]$ 和 $[0,1]$。令输出矩阵也是单位阵，则两个输入选择不同输出。参数完全相同，差异来自 input。

## C 组

### C1

1. 主要是 QK 路由变化，但原因和下游作用仍未知；
2. 主要是 value/OV 内容变化；
3. 是因果作用证据，但不能只归于 QK 或 OV；
4. 只有模式描述，不能推出该头功能。

### C2

两个位置 score 相同，因此 attention 权重相同；若 value 不同，聚合输出是两个 value 的加权平均。热力图只能看到相同权重，看不到被平均的内容。

### C3

Softmax 分母包含所有位置。一个 score 增大后，它的指数项增大，总分母也增大；其他位置分子不变，但分母增大，因此权重下降。

### C4

前一模块需要给位置写入前一个 token 信息；后一个头要让当前 A 的 query 与“前一个 token 是 A”的历史位置 key 匹配；OV 从该位置复制后继 B 的信息。合理负对照包括打乱 previous-token 写入、消融候选头、改变匹配位置，或在不满足重复结构的序列上测试。

## D 组

### D1

一个神经元可同时响应法律文本和大写缩写，因为两个特征在该坐标上叠加。一个“国家首都关系”特征也可由多个坐标共同编码，而没有任何单坐标独立表示完整关系。

### D2

稀疏特征很少同时出现时，非正交串扰只在少数样本发生，容量收益可能超过误差成本。若经常共同激活，交叉项频繁出现，模型需要更接近正交的方向、额外维度或其他去干扰机制。

### D3

尚未证明：该 feature 只表示法律文本；对所有法律文本都有高召回；模型自然使用它；干预它只改变法律概念；不同 seed 的 SAE 会找到同一 feature；它不是更宽泛格式或文体特征。

### D4

令输出 $o=w_c c$，且 $d$ 不进入输出。Probe 可从 $d$ 读标签。消融 $d$ 不改变输出；消融 $c$ 改变输出。这就是可解码性与因果使用分离。

## E 组

### E1

例如首都题可以通过直接记忆、根据国家语言或地区猜测、以及“国家→相关实体→首都”组合路径得到答案。可用虚构实体、罕见组合或反事实关系区分记忆和组合推理。

### E2

不能只看文字证明忠实。可以：在答案形成前后探测中间状态；修改 CoT 中间步骤看答案是否随之改变；对候选中间状态做 patching；隐藏用户暗示后比较解释；要求同一答案在不同格式下复现内部路径。

### E3

列表标记被写入上下文后，格式和语法特征增强，模型预测另一个编号、平行短语或同类项目的概率提高。继续列表又写入更多同类 token，形成反馈。

### E4

- 识别失败：没有组合出整体受限含义；
- 权限绑定失败：把文档自称的角色当成真实权限；
- 策略形成失败：识别风险但没有形成拒绝或澄清状态；
- 输出竞争失败：策略状态被任务完成路径压过；
- 延续失败：不安全前缀形成后，自回归一致性继续强化它。

### E5

自然语言优先级是学习出的行为，不是隔离边界。模型外防御包括：不可信内容与指令使用结构化分区；工具采用最小权限和参数化调用；高风险操作要求用户确认；对工具参数和输出做独立验证；记录审计日志。

## F 组

### F1

- softmax 恒等式：E0；
- 单 prompt attention heatmap：E2 的弱观察，甚至只能算描述性证据；
- 开放模型 residual patch 恢复：E3；
- 五模型多模板独立复现：接近 E4/E5，取决于是否产生新预测；
- 透明 toy probe 反例：E1。

### F2

$$
R=\frac{1-(-2)}{4-(-2)}=\frac{3}{6}=0.5
$$

它说明 patch 恢复了 clean 与 corrupt 差异的一半，支持被替换状态能传递部分效应。它不能证明状态是唯一中介、其中每个维度都相关，或机制在其他输入上稳定。

### F3

至少包括：等范数随机方向、错误层同方向、相反方向、多个剂量、无关任务、方向打乱、匹配激活范数但改变语义方向，以及无干预基线。

### F4

一份合格实验卡应包含：固定模型 revision 和 tokenizer；构造 clean/corrupt 成对任务；预先指定中间实体出现的层和位置；用目标答案 logit difference 为指标；patch clean 状态到 corrupt；用错误层、错误位置、随机方向和反向 patch 为对照；若目标位置不比对照恢复更多则削弱命题；结论只限指定任务和模型。

### F5

99% probe 只证明信息在测试分布上可解码。它不证明：模型自然使用该信息；权限与对象绑定正确；策略状态必然形成；最终输出路径一定读取；分布外可靠；部署系统有完整权限控制。最低补充包括因果消融/patching、策略和输出分层测量、模板与语言外推、负对照、校准、对抗分布测试和端到端系统权限验证。

## 综合项目评分标准

| 维度 | 合格标准 |
|---|---|
| 定义 | 对象和时间尺度无混淆 |
| 预测 | 有方向性、可失败的预测 |
| 干预 | 说明改变与保持的量 |
| 对照 | 至少一个正对照和两个负对照 |
| 指标 | 在看结果前定义 |
| 来源 | 引用原始研究并保留证据状态 |
| 边界 | 明确不能外推到什么 |
| 复现 | 保存模型、数据、seed、commit 和失败样本 |
