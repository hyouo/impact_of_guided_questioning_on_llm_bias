> **覆盖边界：2026-09-01 官网首页时间线，共 56 条唯一来源。**  
> 本文不是原文替代品，也不逐句翻译。每条来源都被压缩为五个问题：**研究什么、怎样研究、真正发现了什么、它在统一理论里处于哪里、不能据此宣称什么**。

## 10.1 阅读规则

不同页面的证据强度不同：

| 标签 | 应怎样理解 |
|---|---|
| 研究论文 | 有相对完整的方法、实验和局限，但仍只对特定模型与任务负责 |
| 研究更新 | 实验室阶段性结果；适合了解方向、反例和失败，不应当作成熟定律 |
| 工具/论文 | 工具与案例并重；可视化或接口本身不自动产生因果证据 |
| 观点/方法论 | 提供概念框架和研究战略，不是经验事实 |
| 教学/基础设施 | 帮助学习或开展研究，不承载独立机制结论 |
| 交叉发布 | 与 thread 理论相关，但页面发布在其他 Anthropic 站点 |
| 研究前史 | 提供 circuits 范式的历史和方法来源 |

对每一条来源，本仓库采用以下解释约束：

1. **可解码信息不等于模型实际使用的信息。**
2. **相关激活不等于因果机制。**
3. **替代模型拟合输出不等于复制了原模型机制。**
4. **局部 prompt 的回路不等于全模型全分布回路。**
5. **小模型中的存在性结果不自动外推到前沿模型。**
6. **能报告内部状态不等于意识，情绪概念有功能不等于主观体验。**
7. **安全分析描述机制类别，不收录可直接复用的越狱载荷。**

# 2026

## 2026-08-21｜[Characterizing interference weights in a tiny language model](https://transformer-circuits.pub/2026/interference_effectiveness_helpfulness/index.html)

**证据状态：** 研究论文

**研究问题。** 如果把模型改写到较可解释的特征坐标中，虚拟权重的绝对值是否就能直接告诉我们哪些连接真正重要？

**方法与对象。** 在一个小型、一层语言模型中，把特征间虚拟连接分成数值大小、在数据分布上的实际效应（effectiveness）以及对损失的帮助或伤害（helpfulness），并进行系统移除实验。

**核心精华。** 最大的理论贡献是把“看起来很大的连接”和“经常真正改变模型计算的连接”分开。源特征若很少激活、目标路径若被抵消，数值很大的虚拟权重也可能几乎无效；反之，较小连接可以因频繁共激活而重要。按 effectiveness 排序移除大量低效连接，对损失影响很小，但剩余有效连接仍然很多，说明找到特征基底并不会自动把模型变成一张极稀疏、容易阅读的程序。

**在统一理论中的位置。** 它把权重解释从静态矩阵检查推进到“权重 × 激活 × 数据分布 × 下游因果效果”的框架，也是本仓库区分 magnitude、contribution、effectiveness、helpfulness 的直接来源。

**证据边界。** 模型非常小且只有一层；有效性和帮助性的具体定义依赖分析基底与任务分布，不能直接外推为所有前沿模型的全局规律。

## 2026-07｜[Verbalizable Representations Form a Global Workspace in Language Models](https://transformer-circuits.pub/2026/workspace/index.html)

**证据状态：** 研究论文

**研究问题。** 模型内部哪些表示容易被语言报告、按指令控制并被多个任务复用？这些表示是否形成一个功能上的“全局工作区”？

**方法与对象。** 使用 Jacobian-based lens 等工具识别一个更可语言化的表示子空间（J-space），再测试它能否被读出、写入、组合、用于推理以及被不同下游模块复用。

**核心精华。** 研究提出：大量语法和常规处理仍可在自动、局部的回路中完成，但一小部分内部状态更容易被模型语言化、主动操纵并用于灵活多步任务。这个子空间通常只解释整体激活方差的一小部分，却能对报告、控制和推理产生较大作用。它提示我们应区分“所有内部计算”与“进入可报告、可组合工作区的计算”。

**在统一理论中的位置。** 连接了机制可解释性、外显推理与序列级计算，解释为什么模型可能拥有大量不可报告的自动处理，同时又能把部分中间变量写成语言继续计算。

**证据边界。** “global workspace”是功能类比，不是意识证明；J-space 是方法定义下的近似子空间，无法保证捕捉全部可报告或真正因果的状态。

## 2026-06｜[Circuits Updates — June 2026](https://transformer-circuits.pub/2026/june-update/index.html)

**证据状态：** 研究更新

**研究问题。** 逐 token 的特征分解往往被局部语法和表面形式淹没，能否直接学习表示整轮对话或较长片段的稀疏变量？

**方法与对象。** 探索 turn-averaged sparse autoencoders，把一段对话轮次中的激活聚合后再进行字典学习。

**核心精华。** 逐位置 SAE 容易产生大量与标点、位置和短程语法相关的特征；跨 token 聚合可能突出任务、话题、意图或整轮行为等更宏观变量。这代表机制可解释性从“局部 token 解释”向“对话级状态解释”迈进。

**在统一理论中的位置。** 补足了从微观神经活动到中尺度行为状态的分析层，是“如何缩放观察尺度”问题的一种实验方案。

**证据边界。** 这是阶段性更新；聚合会提高宏观可读性，也可能抹掉真正决定行为的时间顺序和局部因果结构。

## 2026-05｜[Circuits Updates — May 2026](https://transformer-circuits.pub/2026/may-update/index.html)

**证据状态：** 研究更新

**研究问题。** 怎样判断一个可命名特征是否真的适合用于 steering，而不是只在激活可视化中显得相关？

**方法与对象。** 比较特征标签、unembedding 方向和下游连接信息，并探索用下游影响指标预测干预效果。

**核心精华。** 特征“表示什么”与特征“被模型拿来做什么”并不相同。仅看最高激活样本或直接词汇投影，经常不足以预测 steering；沿着真实下游连接观察它如何影响其他特征和输出，更接近功能解释。

**在统一理论中的位置。** 强化本仓库的核心区分：语义可读性不是功能重要性，干预选择应依赖下游因果结构。

**证据边界。** 属于初步结果；steering 成功也可能是分布外强迫，不自动说明自然运行时模型以同样方式使用该特征。

## 2026-05-07｜[Natural Language Autoencoders Produce Unsupervised Explanations of LLM Activations](https://transformer-circuits.pub/2026/nla/index.html)

**证据状态：** 研究论文

**研究问题。** 能否让模型把高维激活压缩成自然语言，再从这段语言重建原激活，从而得到无需人工标签的解释？

**方法与对象。** 训练 activation verbalizer 将激活转换成文字，再训练 activation reconstructor 根据文字恢复激活；以重建能力而非人工语义标签作为主要学习信号。

**核心精华。** NLA 把自然语言变成一种可读的激活瓶颈。它能发现任务状态、评估意识或潜在目标等难以由单个 SAE 特征描述的模式，并允许编辑文字后重新注入近似状态。其价值不是宣称语言描述等于真实机制，而是提供更高带宽的假设生成与审计接口。

**在统一理论中的位置。** 扩展了“解释基底”的概念：除了稀疏向量，还可以使用可组合的自然语言描述近似内部状态。

**证据边界。** verbalizer 本身是高容量模型，可能从上下文推断、幻觉、重复输入信息或形成不透明编码；重建成功也不证明文字逐字忠实，必须用对照、去上下文测试和因果干预验证。

## 2026-05-04｜[HeadVis: An Interactive Tool For Investigating Attention Heads](https://transformer-circuits.pub/2026/headvis/index.html)

**证据状态：** 工具/论文

**研究问题。** 注意力头是否真能用“复制头”“归纳头”等单一标签概括，还是需要在完整数据分布上研究其高秩、上下文相关行为？

**方法与对象。** 提供交互式工具，在大规模数据上查看注意力模式、输入输出特征和条件行为，并以多个头为案例分析。

**核心精华。** 同一个头可以在不同输入子分布上执行不同操作；许多行为是模糊的、条件化的或由多个低秩成分叠加而成。局部热力图容易诱导“这个头就是某功能”的过度故事。可靠解释需要同时研究 QK 选择、OV 写入、全分布覆盖和反事实输入。

**在统一理论中的位置。** 把 attention 解释从单例可视化推进到分布级功能分析，并为 attention superposition 提供直观证据。

**证据边界。** 可视化能发现结构，但不能独立证明因果；工具展示的案例和分析投影也可能遗漏替代路径。

## 2026-04-02｜[Emotion Concepts and their Function in a Large Language Model](https://transformer-circuits.pub/2026/emotions/index.html)

**证据状态：** 研究论文

**研究问题。** 模型中的情绪概念只是文本相关性，还是会作为内部变量因果性地调节后续行为？

**方法与对象。** 识别与情绪相关的内部表示，分析其几何结构，并通过注入、抑制等干预观察输出行为变化。

**核心精华。** 部分情绪概念在表示空间中呈现可解释结构，并能因果改变语气、判断或行为倾向。研究还发现某些方向与价度、唤醒度等心理学维度相近，说明语义表征既可离散命名，也可具有连续几何。

**在统一理论中的位置。** 是“概念表征能否真正参与计算”的重要案例，也把特征、几何和行为干预连接起来。

**证据边界。** 模型拥有并使用“情绪概念”不等于模型具有主观情绪体验；干预结果依赖模型、层和提示分布。

# 2025

## 2025-12｜[Circuits Cross-Post — Activation Oracles](https://alignment.anthropic.com/2025/activation-oracles/)

**证据状态：** 交叉发布

**研究问题。** 能否训练一个模型直接读取另一个模型的激活，并用自然语言回答关于这些激活的问题？

**方法与对象。** 训练 activation oracle 接收内部激活及问题，在多种分布内与分布外审计任务上评估其回答能力。

**核心精华。** Activation Oracle 提供比固定 probe 更灵活的问答接口，可以询问激活中编码的主题、目标或异常状态。在若干任务中，它展现出一定分布外泛化，且数据数量与多样性提升性能；这说明内部状态可通过学习得到高带宽读出。

**在统一理论中的位置。** 与 NLA、introspection、J-space 一起构成“激活到语言接口”研究谱系。

**证据边界。** Oracle 可能根据上下文和任务先验推断答案，而非单纯读取激活，也可能自信地编造解释；成本高，且需要激活访问权限。

## 2025-11｜[Circuits Updates — November 2025](https://transformer-circuits.pub/2025/november-update/index.html)

**证据状态：** 研究更新

**研究问题。** 安全训练产生的拒绝倾向是否只在输出末端加一个否决信号，还是会更早地改变模型的信息路由？

**方法与对象。** 构造 harm-pressure 条件，分析正确答案表示、拒绝/重定向特征与答案选择注意力头之间的 QK 交互，并进行负向 steering。

**核心精华。** 在有害框架下，模型内部仍可保留正确答案信息，但拒绝相关 query 特征会与危险检测 key 特征交互，干扰负责读取答案的位置。抑制相关拒绝特征可显著恢复任务准确率。安全行为因此可能通过改变“读什么”而不是只改变“最后说什么”来实现。

**在统一理论中的位置。** 为“安全信号存在、知识存在、最终行为仍失败”提供了具体注意力路由机制。

**证据边界。** 研究针对特定模型与任务，属于更新而非完整普遍理论；恢复答案的干预也不能证明所有拒绝机制都采用同一路径。

## 2025-10｜[Emergent Introspective Awareness in Large Language Models](https://transformer-circuits.pub/2025/introspection/index.html)

**证据状态：** 研究论文

**研究问题。** 模型能否区分由外部文本引发的概念与直接注入内部激活的概念，并正确报告后者来自自身内部？

**方法与对象。** 向中间层注入概念方向，设计 internality、grounding 等标准，测试模型是否识别、报告或利用注入状态。

**核心精华。** 部分模型在合适层位、强度和提示条件下，能够以有限比例识别注入概念，甚至报告某个想法似乎并非来自文本。这是一种受条件限制的功能性内省现象，表明模型有时能把内部状态本身作为计算对象。

**在统一理论中的位置。** 把可解释性从外部研究者读激活推进到“模型能否读取自身激活”，并与 J-space、Activation Oracles 形成连续谱。

**证据边界。** 成功率有限且高度依赖设置；不能据此推断持续自我模型、意识或主观体验。注入也可能通过普通下游因果路径诱导相应文字。

## 2025-10｜[Circuits Updates — October 2025](https://transformer-circuits.pub/2025/october-update/index.html)

**证据状态：** 研究更新

**研究问题。** 不同文字呈现形式能否共享抽象特征？字典学习的初始化方式能否提高质量？

**方法与对象。** 比较普通文本、ASCII、SVG 等视觉化文字形式的内部表示，并探索基于真实数据点的 dictionary 初始化。

**核心精华。** 某些跨呈现形式特征提示模型可在表面模态不同的情况下形成共享语义；更贴近数据几何的初始化能改善稀疏度与重建指标。两者共同说明：特征学习既受语义结构影响，也受优化和初始化影响。

**在统一理论中的位置。** 提醒读者不要把任何一次 SAE 分解视为唯一真相，同时展示抽象表示可能跨越表面编码。

**证据边界。** 属于研究更新；指标改善不等于特征更真实，跨形式共享也可能来自训练共现或共同输出任务。

## 2025-10｜[When Models Manipulate Manifolds: The Geometry of a Counting Task](https://transformer-circuits.pub/2025/linebreaks/index.html)

**证据状态：** 研究论文

**研究问题。** 模型如何表示和操作字符数、行宽、剩余数量等连续或有序变量？单个离散特征是否足够描述这种计算？

**方法与对象。** 研究换行/计数任务，结合 SAE/crosscoder 特征、低维几何、QK 变换和因果干预追踪内部计数。

**核心精华。** 数值状态可沿曲线或低维流形编码，而多个离散特征像覆盖流形不同区段的局部坐标。注意力的 QK 变换会旋转、对齐或扭转这些流形，以比较当前位置和目标宽度。该工作展示了“离散特征图”和“连续几何图”并非竞争理论，而可能是同一内部对象的不同分辨率。

**在统一理论中的位置。** 为从 feature-centric 解释扩展到 manifold-centric 解释提供代表性案例，并说明 attention 可以操作几何结构。

**证据边界。** 研究聚焦一个精心选择的计数任务；流形结构能否普遍描述开放域语义仍是开放问题。

## 2025-09｜[Circuits Updates — September 2025](https://transformer-circuits.pub/2025/september-update/index.html)

**证据状态：** 研究更新

**研究问题。** 随着上下文增长，模型的语言特定表示是否会逐渐转化为更跨语言、任务相关的表示？

**方法与对象。** 比较不同语言提示在序列不同位置的特征重叠与表示相似性。

**核心精华。** 在更长上下文或任务信息积累后，不同语言的表示可能出现更高重叠，提示上下文会把早期表面语言差异逐渐映射到共享任务变量。

**在统一理论中的位置。** 连接了多语言表示、in-context learning 和抽象变量形成。

**证据边界。** 特征重叠是证据而非完整机制；共享坐标并不意味着所有语言都完全等价，也不排除英语等高资源语言的特权路径。

## 2025-08｜[Circuits Updates — August 2025](https://transformer-circuits.pub/2025/august-update/index.html)

**证据状态：** 研究更新

**研究问题。** Persona 如何改变模型行为：它会删除知识、替换整个模型，还是调制知识访问与报告？

**方法与对象。** 构造角色设定，追踪 persona 相关特征、数学答案表示和输出行为，并进行特征干预。

**核心精华。** 模型在扮演低知识角色时，内部仍可能保留正确答案，却选择输出“不知道”或更符合角色的表达。Persona 因而更像一个控制状态，调制哪些知识被报告、用什么语气报告以及哪些策略被激活，而不是把所有底层能力替换掉。

**在统一理论中的位置。** 给“输入既是数据也是控制信号”提供清晰案例，并解释角色提示为何能广泛改变行为。

**证据边界。** 不同 persona 可能通过不同回路实现；观察到知识可解码不等于模型在自然状态中一定会使用它。

## 2025-07｜[A Toy Model of Mechanistic (Un)Faithfulness](https://transformer-circuits.pub/2025/faithfulness-toy-model/index.html)

**证据状态：** 研究更新

**研究问题。** 一个 replacement model 若能很好拟合原模型输出，是否就意味着它使用了相同内部机制？

**方法与对象。** 构造可知真相的玩具模型，训练替代模型或 transcoder，并比较函数拟合与内部机制。

**核心精华。** 两个模型可以在观察数据上给出相同输出，却依赖不同中间变量或路径。仅凭重建误差、输出一致性或局部拟合，不能保证 mechanistic faithfulness。加入 Jacobian、干预或反事实约束，可能减少但不能完全消除这个问题。

**在统一理论中的位置。** 是所有 SAE/transcoder/attribution graph 解读的核心警告：分析模型本身也需要被验证。

**证据边界。** 玩具反例证明的是“不保证”，不是说所有 replacement model 都不可信；现实模型中真机制未知，验证更困难。

## 2025-07｜[Tracing Attention Computation Through Feature Interactions](https://transformer-circuits.pub/2025/attention-qk/index.html)

**证据状态：** 研究论文

**研究问题。** 归因图若只捕捉 OV 写入，怎样解释注意力为什么选择某个源位置？

**方法与对象。** 把双线性 QK 分数展开为 query 特征与 key 特征的成对交互，并将这些交互接入 attribution graph；用 induction、反义词、多选题等案例验证。

**核心精华。** 注意力选择不是由单个 token 标签决定，而是由当前位置 query 状态与候选位置 key 状态的交互决定。把 QK 分数分解为 feature-pair contribution 后，可以解释“哪个查询需求遇到了哪个可读线索”，再连接到 OV 写入和输出。

**在统一理论中的位置。** 补上 circuit tracing 中“为什么读这里”的缺口，使 attention 解释从热力图走向机制分解。

**证据边界。** softmax 会让所有位置相互耦合，长上下文的归因与反事实仍很困难；特征基底和替代模型误差继续限制忠实性。

# 前史

## 2020-03/2021-04｜[Original Distill Circuits Thread](https://distill.pub/2020/circuits/)

**证据状态：** 研究前史

**研究问题。** 神经网络是否可以像生物系统或程序一样，被分解成特征和可复用回路？

**方法与对象。** 在视觉模型中结合特征可视化、权重分析和交互式案例，提出 circuits 研究范式。

**核心精华。** Distill thread 建立了“特征是表示单位、回路是特征间连接”的基本观念，并展示 curve detectors 等视觉回路。Transformer Circuits 继承其多尺度、交互和逆向工程精神，但语言模型中的 token 路由、序列反馈和 superposition 带来新的困难。

**在统一理论中的位置。** 是整个项目的方法论前史，说明机制可解释性从视觉网络迁移到 Transformer 的连续性。

**证据边界。** 视觉卷积网络的局部空间结构与 Transformer 不同；具体回路结论不能直接迁移到语言模型。
