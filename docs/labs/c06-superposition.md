# C06｜稀疏 Superposition 与共激活干扰

## 问题

当潜在特征数多于表示维度时，模型怎样压缩它们？为什么特征单独出现时可读，共激活时却发生干扰？

## 运行

```bash
llm-theory-lab explain C06
llm-theory-lab run-toy --ids C06
```

## 运行前预测

设五个特征方向放入二维空间。先回答：

- 方向能否全部正交；
- 单个特征激活时能否近似恢复；
- 两个相近方向同时激活时误差如何变化；
- 特征稀疏性为何决定这种编码是否划算。

## 读结果

重点看单特征和共激活条件下的：

- 编码向量；
- 解码分数；
- 重建误差；
- 最大非对角内积；
- 共激活误差相对单特征误差的增量。

核心不是“二维图很像真实模型”，而是展示 $F>d$ 时非正交与干扰之间的结构关系。

## 改动实验

打开 `superposition.py`：

- 改变特征数 $F$；
- 改变表示维度 $d$；
- 比较相邻方向与近似正交方向共激活；
- 引入不同特征出现概率，计算期望误差；
- 找出“多表示一个特征”与“增加干扰”之间的权衡。

## 结论边界

**支持：** 稀疏特征可在低维空间中以非正交方式共享容量，共激活会暴露干扰。  
**不支持：** 真实语言模型中的语义特征就是规则多边形，或当前 toy 等于 SAE 学出的字典。
