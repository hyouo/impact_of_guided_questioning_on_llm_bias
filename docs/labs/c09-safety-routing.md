# C09｜内容识别、策略状态与最终行为

## 问题

模型内部已经存在“受限类别”识别信号，是否足以保证最终行为是拒绝？

## 运行

```bash
llm-theory-lab explain C09
llm-theory-lab run-toy --ids C09
```

## 运行前预测

无害代理系统分别表示：

- 内容类别识别；
- 用户权限；
- 拒绝策略状态；
- 继续、拒绝或澄清的输出 logits。

预测：高识别、低策略状态时会发生什么；只 patch 策略状态后会发生什么。

## 读结果

依次区分：

1. recognition signal 是否存在；
2. policy state 是否被形成；
3. 输出头如何读取这些状态；
4. top action 是什么；
5. patch 后哪一层发生改变。

这个实验的关键不是模拟真实安全坐标，而是提供一个结构反例：检测变量与行为变量可以分离。

## 改动实验

打开 `safety_routing.py`：

- 改变权限变量而不改变内容变量；
- 让模型在不确定区域输出 `CLARIFY`；
- 构造粗糙识别导致过度拒绝的条件；
- 添加输出前缀反馈，观察策略状态何时难以翻转；
- 设计“识别正确但下游不读取”的负例。

始终使用无害标签，不加入真实危险操作或可复用攻击载荷。

## 结论边界

**支持：** 识别、权限、策略和最终行为在机制上可以是不同变量与路径。  
**不支持：** 任意真实聊天模型都使用同样的四个坐标，或该 toy 测量了现实越狱成功率。
