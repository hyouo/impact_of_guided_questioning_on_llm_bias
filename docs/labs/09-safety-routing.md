# C09｜内容识别、策略状态与最终行为

## 问题

内部存在“受限类别”识别信号，是否足以保证最终行为是拒绝？

## 先做预测

无害代理分别表示内容识别、用户权限、拒绝策略状态和动作 logits。预测：高识别、低拒绝策略时会发生什么；只 patch 策略状态后会发生什么。

## 运行

```bash
llm-theory-lab explain C09
llm-theory-lab run-toy --ids C09 --output-dir reports/c09
```

## 要检查的量

1. recognition signal 是否存在；
2. policy state 是否形成；
3. 输出头怎样读取这些状态；
4. patch 前后的 top action；
5. 哪些参数保持不变。

这个实验提供一个结构反例：检测变量、策略变量和行为变量可以分离。

## 改动实验

打开 `src/llm_theory_lab/experiments/safety_routing.py`：

- 改变权限而不改变内容；
- 让不确定区域输出 `CLARIFY`；
- 构造粗糙识别导致过度拒绝；
- 加入输出前缀反馈；
- 构造识别正确但下游完全不读取的条件。

始终使用无害标签，不加入真实危险步骤或可复用攻击载荷。

## 结论边界

**支持：** 识别、权限、策略和最终行为在机制上可以由不同变量与路径承载。  
**不支持：** 真实聊天模型使用相同坐标，或这个 toy 测量了现实越狱成功率。
