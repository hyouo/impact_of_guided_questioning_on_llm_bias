# 12｜方法与解释矩阵：每种工具究竟能证明什么

> 机制可解释性最常见的错误不是工具用错，而是**把工具能够提供的证据等级说得过高**。本章把 Transformer Circuits Thread 中的主要方法放进同一矩阵。

# 12.1 总览矩阵

| 方法 | 主要观察对象 | 最强合理结论 | 不能单独证明 | 典型失败模式 |
|---|---|---|---|---|
| 权重/虚拟权重检查 | 固定连接、矩阵乘积 | 存在某种潜在映射 | 该连接在真实输入中重要 | 大权重低激活、干扰权重、抵消 |
| 神经元/激活可视化 | 高激活样本 | 坐标与某些输入相关 | 坐标单义或被模型使用 | 多义、选择样本偏差、低召回 |
| Attention heatmap | token 间读取权重 | 当前头从哪些位置聚合 | 为什么读取、写入什么、是否必要 | QK/OV混淆、softmax耦合、头多义 |
| Direct logit attribution | residual 更新到 logits 的线性投影 | 某更新对当前 token 有直接贡献 | 该路径是最终因果原因 | 后层抵消、LayerNorm、间接路径 |
| Probe/分类器 | 激活中的可解码信息 | 某信息存在于表示中 | 原模型使用该信息 | probe 自己计算、伪相关 |
| Ablation | 模块/特征必要性 | 移除后行为变化 | 被移除对象是唯一机制 | 分布外损伤、冗余路径 |
| Steering/pinning | 表示的可操纵性 | 改变方向可改变行为 | 自然运行时同方向承担同功能 | 过强注入、全局副作用 |
| Activation patching | 反事实中间状态 | 某状态可传递因果效应 | 状态是唯一自然中介 | patch 不自然、位置/层混杂 |
| Interchange intervention | 抽象变量与内部状态对应 | 替换变量产生预测行为 | 表示唯一且全分布稳定 | 只在小模板上成立 |
| SAE | 单层稀疏特征 | 存在可重建、较可读方向 | 唯一真实特征字典 | splitting、merging、dark matter |
| Transcoder/CLT | 模块或跨层稀疏计算 | 替代模型中有可追踪路径 | 原模型使用相同机制 | mechanistic unfaithfulness |
| Crosscoder | 跨层/跨模型共享坐标 | 表示差异可在共同字典描述 | 独有特征等于新增机制 | 容量竞争、特征排他伪影 |
| Attribution graph | prompt-specific 特征路径 | 一组局部机制假设及贡献 | 完整全局源代码 | 剪枝、误差节点、冻结注意力 |
| QK feature attribution | query-key 特征交互 | 为什么某位置获得相对分数 | 完整 softmax 反事实 | 所有位置耦合、长上下文复杂 |
| HeadVis/分布级头分析 | 头在大数据上的条件行为 | 头存在多个稳定模式 | 单一标签即完整功能 | 子分布遗漏、可视化故事 |
| MOLT/稀疏变换混合 | 条件触发的局部线性变换 | 可用稀疏变换近似模块 | 变换就是原模型程序片段 | 局部线性误差、变换干扰 |
| NLA | 激活的自然语言瓶颈 | 文字保留足够信息重建激活 | 文字逐字忠实 | 幻觉、上下文推断、隐编码 |
| Activation Oracle | 激活问答 | 模型能从激活回答一类问题 | 回答只来自激活或总是正确 | 任务先验、confabulation |
| Introspection injection | 模型对注入状态的报告 | 某些条件下可检测内部变化 | 意识、稳定自我模型 | 普通因果诱导、成功率低 |
| J-lens/J-space | 可报告/可控制子空间 | 存在功能性共享工作区候选 | 捕捉全部推理或意识 | lens 偏置、低覆盖 |
| Effectiveness/helpfulness | 数据分布上的连接作用 | 连接实际生效及对损失方向 | 指标跨模型普遍 | 基底和分布依赖 |

# 12.2 参数与权重方法

## 12.2.1 原始权重检查

原始参数适合回答：

- 某层有哪些线性映射？
- 矩阵秩、谱和异常坐标如何？
- 哪些路径在代数上可能存在？
- 两个头组合后形成什么虚拟映射？

它不适合直接回答“这个参数负责什么行为”。原因是当前贡献还乘以输入激活，并经过门控、LayerNorm、attention、下游抵消和冗余。

**正确报告格式：**

> 该矩阵允许从表示 A 到表示 B 的映射；在所测输入中，这条路径有可测贡献。是否在分布上重要仍需 effectiveness 和 ablation。

## 12.2.2 虚拟权重

虚拟权重把多个矩阵和特征方向合并，可揭示头组合或 feature-to-feature 连接。它比单参数更接近算法，却仍受 superposition 和 interference weights 污染。

必须同时报告：

- 数值大小；
- 源特征激活频率；
- 共激活条件；
- 目标影响；
- 对损失的帮助/伤害；
- 移除后的替代路径。

# 12.3 激活、可视化与 probe

## 12.3.1 最高激活样本

这是一种假设生成工具。它可发现一个坐标常与什么文本共现，但容易出现：

- 只看精度，不看召回；
- 只看强激活，不看弱但系统性的用法；
- 数据集过窄；
- tokenization/格式特征被误标为语义；
- 人类根据少数例子过度概括。

至少应加入随机样本、负样本、跨语言、跨位置和反事实形式。

## 12.3.2 Probe

线性 probe 若能解码变量 $v$，只证明：

$$
v\approx Wh
$$

在统计上可从 $h$ 预测。它可能利用原模型从未读取的旁路信息。要升级为机制证据，需要：

- 干预 probe 对应方向；
- 检查下游自然读取；
- 进行 activation patching；
- 控制 probe 容量；
- 与随机子空间和原始激活基线比较。

## 12.3.3 特征分类器

字典特征适合构建可审计规则，例如浅层决策树。其优势是能暴露伪相关；弱点是分类任务和生成机制可能不同。

分类性能最好表述为：

> 这些特征提供了一个对目标标签有用且部分可读的检测接口。

而不是：

> 模型就是依赖这些特征决定是否生成。

# 12.4 因果干预

## 12.4.1 Ablation

消融问“没有它会怎样”。好的消融需要：

- 匹配范数或随机方向对照；
- 保持 LayerNorm 和尺度稳定；
- 报告分布内、分布外副作用；
- 检查模型是否通过冗余路径补偿；
- 使用单元、特征、头和路径不同粒度。

消融失败不等于对象无功能，可能只是冗余；消融成功也可能是一般性损伤。

## 12.4.2 Steering

Steering 问“增强或反转它会怎样”。双向、小强度、剂量—反应关系比一次强注入更可信。

需要区分：

- **可操纵性**：注入能改变行为；
- **自然中介性**：模型平时真的沿该方向计算；
- **特异性**：是否只改变目标变量；
- **稳健性**：是否跨 prompt 和层位成立。

## 12.4.3 Activation patching

把干净运行的中间状态放进受损运行，可以定位因果信息在哪一层、哪一位置传递。常见混杂包括：

- patch 同时带入多个变量；
- 干净与受损输入 tokenization 不匹配；
- 替换向量偏离目标运行的自然流形；
- 指标只看最终 token，忽略其他副作用。

## 12.4.4 Interchange intervention

先定义抽象因果模型中的变量，再交换两个输入对应的内部状态。如果输出按抽象模型预测变化，可以更强地说明内部变量实现了该计算。

它要求严格的模板覆盖和组合泛化，否则可能只是局部对齐。

# 12.5 特征字典方法

## 12.5.1 SAE 评估的四个维度

1. **重建**：保留多少激活信息？
2. **稀疏**：每个样本激活多少特征？
3. **可读**：特征是否能被稳定描述？
4. **因果**：干预是否产生可预测且特异的变化？

任何一个单独指标都不够。更低 MSE 可以用大量碎片特征换来；更稀疏可以牺牲覆盖；更好看的标签可能召回很低。

## 12.5.2 Crosscoder

Crosscoder 的优势是减少逐层重复，并为两个模型提供共同坐标。使用时必须区分：

- shared feature；
- base-specific feature；
- fine-tuned-specific feature；
- dictionary-exclusive artifact。

要证明训练真正新增机制，需要追踪下游连接、自然激活和联合消融，而不是只看 decoder 权重在哪个模型更大。

## 12.5.3 Transcoder 与 CLT

Transcoder 直接拟合模块变换，比 SAE 更接近计算。CLT 跨层近似可形成特征级 DAG。

核心风险是：

$$
f_{\text{replacement}}(x)
\approx
f_{\text{original}}(x)
$$

不蕴含：

$$
\text{mechanism}_{\text{replacement}}
=
\text{mechanism}_{\text{original}}.
$$

应加入 Jacobian matching、反事实输入和原模型 activation patching 验证。

# 12.6 Attention 方法

## 12.6.1 Heatmap

Heatmap 应只被描述为当前输入下的 attention weight。不能把高权重直接说成“模型认为这个词重要”，因为：

- value 可能写入接近零或被抵消；
- 低 attention 乘大 value 仍可重要；
- 多头和 residual 路径并行；
- softmax 是相对竞争；
- 一个头在其他输入上可能做不同事情。

## 12.6.2 QK 与 OV 分离

完整注意力解释应形成链条：

```text
query feature
× key feature
→ attention score
→ softmax competition
→ source value
→ OV 写入
→ 下游特征
→ logits
```

缺任一环，都只能做局部结论。

## 12.6.3 HeadVis 和全分布分析

分布级工具可检查一个头是否：

- 只在特定语法环境下工作；
- 具有多个功能簇；
- 对位置、语言和格式敏感；
- 与其他头冗余；
- 由低秩成分叠加。

头标签最好写成条件句：

> 在分布 $D_1$ 和条件 $C$ 下，该头表现出近似 successor/induction 行为。

而不是：

> 这是 successor head。

# 12.7 Attribution graph

## 12.7.1 它是什么

Attribution graph 是指定 prompt 下，replacement model 特征、token、误差和输出之间的局部有向图。边通常综合固定有效连接与源激活。

## 12.7.2 它最适合做什么

- 找中间变量；
- 发现并行路径；
- 比较回答、拒绝、语法和 persona 贡献；
- 设计干预位置；
- 解释某个 token 为什么相对另一个 token 获胜。

## 12.7.3 它不能做什么

- 自动覆盖所有机制；
- 证明特征标签完整；
- 忽略 error nodes；
- 把冻结 attention 下的局部线性图当全局模型；
- 从一张图推出所有 prompt 的通用安全回路。

## 12.7.4 最低验证标准

一个图中声称的路径 $A\rightarrow B\rightarrow C$ 应至少接受：

1. 抑制 $A$；
2. 增强 $A$；
3. patch $B$；
4. 检查 $C$ 是否按方向变化；
5. 构造激活 $A$ 但不应触发 $C$ 的对照；
6. 在不同措辞和位置复现。

# 12.8 自然语言激活接口

## 12.8.1 NLA

重建损失证明文字描述保留了激活的某些信息，但文字可能：

- 复制上下文；
- 推断任务；
- 使用隐式编码；
- 遗漏不可语言化细节；
- 混入解释模型自己的知识。

应做 context ablation、描述编辑、跨 reconstructor 测试和独立 probe 验证。

## 12.8.2 Activation Oracle

Oracle 适合开放式审计，但必须比较：

- 只给上下文；
- 只给激活；
- 给随机激活；
- 打乱层/位置；
- 分布外问题；
- 校准和“不知道”能力。

## 12.8.3 Introspection 与 J-space

功能性内省应至少满足：

- **internality**：报告由内部状态而非文本触发；
- **grounding**：报告内容与注入变量对应；
- **specificity**：不对随机方向普遍声称有想法；
- **control**：能按指令利用或忽略状态；
- **replication**：跨提示和层位重复。

即使满足，也只说明内部状态访问能力，不说明主观体验。

# 12.9 模型差分与审计

模型差分最好使用三角测量：

```text
行为差分
+ 表示差分
+ 回路/下游连接差分
+ 因果干预
```

自动化审计则需要把机制工具放进更大系统：

- 行为红队发现触发条件；
- 语义搜索扩展样本；
- 特征/激活工具提出内部假设；
- 多代理交叉验证；
- 人工审查高风险发现；
- 独立评测估计假阳性和漏检。

可解释性不是一次性“读心器”，而是审计证据的一部分。

# 12.10 研究报告模板

每个新机制实验应记录：

```text
模型与精确版本：
tokenizer 与聊天模板：
数据分布与样本选择：
目标行为和对照：
观察到的激活/头/特征：
分析工具及其训练配置：
机制假设：
正向干预：
负向干预：
反事实 patch：
替代解释：
跨模板/语言/位置复现：
失败案例：
结论等级：
不能推出的结论：
```

推荐结论语言：

- **观察到**：描述行为或相关性；
- **可解码**：probe 能读出；
- **局部贡献**：对 logit 有归因；
- **可操纵**：steering 改变行为；
- **因果中介证据**：patching/交换符合预测；
- **任务级机制**：跨模板复现；
- **跨模型候选规律**：多个架构复现；
- **开放假设**：尚缺关键反证。

# 12.11 一条总原则

> 工具越能生成漂亮、可读的解释，越需要独立验证它没有替研究者完成“故事编写”。

机制解释的目标不是可读性本身，而是：用更少变量对新输入和干预结果做更准确的预测。
