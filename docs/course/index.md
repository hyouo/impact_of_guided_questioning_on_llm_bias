# 课程导览｜从“会用模型”到“会分析模型”

这条课程主线的目标不是让你记住术语，而是训练一套可复用的分析程序：

```text
先分清对象
→ 再写清因果方向
→ 再找可以观测的量
→ 再做反事实干预
→ 最后限制结论范围
```

## 适合谁

你只需要知道向量、矩阵乘法和概率的基本概念。不会 PyTorch 也能完成 C01–C09；默认透明实验只依赖 NumPy。

## 三种节奏

**快速路线（约 1 小时）**：课程导览、第 1–2 章，运行 C01–C03。  
**核心路线（约 6–8 小时）**：完成第 1–7 章、C01–C09 和对应练习。  
**研究路线（1–2 天起）**：完成综合项目，再读深度参考与原始论文。

## 每章怎么学

每章都采用同一结构：

1. **学完你应该能**：把目标写成可检查能力；
2. **核心模型**：只保留必要数学对象；
3. **逐步理解**：给出具体数值或因果例子；
4. **动手验证**：运行对应实验；
5. **常见误区**：指出最容易发生的逻辑跳跃；
6. **自测**：不看答案先独立解释；
7. **来源**：回到原始研究，不把本仓库当权威替代品。

推荐循环：

```text
读章节 → 写预测 → 运行实验 → 解释指标 → 修改一个变量 → 做练习 → 总结结论边界
```

## 实验状态怎样读

| 状态 | 正确含义 |
|---|---|
| `pass` | 本次预注册数值检查成立 |
| `fail` | 至少一条预注册检查失败 |
| `observational` | 只记录观测，不做二元机制判定 |
| `skipped` | 缺少模型、依赖或运行条件 |

透明实验适合验证恒等式、证明一种结构可能发生，或构造反例推翻错误逻辑。它们不能估计真实前沿模型中的普遍效应大小。

## 开始前的基线问题

先写下答案，不必查资料：

1. 推理时参数会不会因为 prompt 改变？
2. 一个权重很大，是否意味着它对当前输出贡献很大？
3. Attention 权重高，是否意味着该位置决定了答案？
4. 一个概念能被线性 probe 解码，是否意味着模型用了它？
5. 模型已经识别出风险，是否一定会拒绝？

完成课程后重新作答。真正的进步不是术语增加，而是你会主动补上条件、对照、反例和证据边界。
