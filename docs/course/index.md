# 课程导览｜从“会用模型”到“会分析模型”

这条课程主线的目标不是让你记住术语，而是建立一个可反复使用的分析程序：

```text
先分清对象
→ 再写清因果方向
→ 再找可以观测的量
→ 再做反事实干预
→ 最后限制结论范围
```

## 适合谁

你只需要知道向量、矩阵乘法和概率的基本概念。不会 PyTorch 也能完成 C01–C12；所有默认实验只依赖 NumPy。

## 三种节奏

**快速路线（约 1 小时）**：第 1–3 章，运行 C01、C02、C04。  
**核心路线（约 6–8 小时）**：完成第 1–7 章和 C01–C12。  
**研究路线（1–2 天起）**：完成综合项目、进阶练习，再读深度参考和原始论文。

## 学习闭环

每章都按同一个循环完成：

```text
读核心模型
→ 不看答案先做预测
→ 运行对应实验
→ 修改一个条件
→ 解释结果和失败
→ 做练习题
→ 写出结论边界
```

配套入口：

- [十二个实验手册](../labs/index.md)：训练如何操作化命题；
- [基础练习册](../exercises/index.md)：训练推导、反例和实验设计；
- [进阶方法练习](../exercises/advanced.md)：训练基底、冗余和 steering 对照；
- [综合项目](08-capstone.md)：把一条直觉升级为可证伪研究。

不要一开始就看答案。先保存自己的预测，预测错误是课程最有价值的结果之一。

## 每章怎么学

每章都有相同结构：

1. **学完你应该能**：把目标写成可检查能力；
2. **核心模型**：只保留必要数学对象；
3. **逐步理解**：给出具体数值或因果例子；
4. **动手验证**：运行对应实验；
5. **常见误区**：指出最容易发生的逻辑跳跃；
6. **自测**：没有答案提示时先独立解释；
7. **来源**：回到原始研究，不把本仓库当权威替代品。

## 实验状态怎样读

| 状态 | 正确含义 |
|---|---|
| `pass` | 本次预注册数值检查成立 |
| `fail` | 至少一条预注册检查失败 |
| `observational` | 只记录观测，不做二元机制判定 |
| `skipped` | 缺少模型、依赖或运行条件 |

透明实验最适合推翻错误的一般推理，例如“权重越大一定越重要”“probe 能解码就说明模型在使用”“消融无效就说明路径没用”或“steering 成功就找到了自然特征”。它们不能估计真实前沿模型中的效应比例。

## 开始前的基线问题

先保存自己的答案：

1. 推理时参数会不会因为 prompt 改变？
2. 一个权重很大，是否意味着它对当前输出贡献很大？
3. Attention 权重高，是否意味着该位置决定了答案？
4. 一个概念能被线性 probe 解码，是否意味着模型用了它？
5. 单点消融无行为变化，是否意味着该路径未参与计算？
6. Steering 产生行为变化，是否意味着找到了模型自然使用的唯一方向？
7. 模型已经识别出风险，是否一定会拒绝？

完成课程后重新作答。真正的进步不是术语增加，而是你会主动补上范围、对照、反例和证据边界。
